#  Двухосевая столбчатая диаграмма / Двухосевая линейная диаграмма

Двухосевая диаграмма — это эффективный инструмент для отображения различных рядов данных (по величине или по типу) на одной графической панели. Масштаб оси соответствует значениям ряда, а данные представлены в виде маркированных линий или столбцов одинаковой ширины, высота которых отражает величину отображаемого показателя.

При построении такого графика важно помнить, что для него необходимо выбрать только два ряда данных, которые будут отображаться в виде колонок или столбцов.

![Двухосевая столбчатая диаграмма](visualization-charts-biaxial-bar.png)

![Двухосевая линейная диаграмма](visualization-charts-biaxial-line.png)

Чтобы настроить график, откройте панель **Конфигурация графика**. В следующих разделах мы подробно рассмотрим каждую вкладку панели.

## Данные

### Базовые настройки


![Базовые настройки](visualization-charts-biaxial-config-base.png)

#### Исключить итоговые строки
Не показывать итоговые значения в строках.
#### Исключить итоговые колонки.
Не показывать итоговые значения в колонках.
#### Исключить пустые значения
Не показывать ряды без данных (с обрезанием графика).
#### Скрыть пустые значения
Не показывать нулевые значения (без обрезания графика).
#### Скрыть пустые области
Скрывает на графике пустые значения, расположенные в начале и в конце области построения. При этом нулевые значения, находящиеся внутри массива данных, остаются видимыми.

Чтобы скрыть пустые значения из легенды, отметьте опцию **Скрыть пустые значения**. В этом случае график сохранит сдвиг массива данных к началу координат.

#### Показывать всплывающую подсказку
Показывать подсказку при наведении курсора на элемент графика.

#### Показывать значения
Отображать значения для каждого ряда данных. После отметки этой опции появляется раздел конфигурации **Настройки отображения значений**.

### Настройки отображения значений

![Настройки отображения значений](visualization-charts-bar-otobrazh-znach.png)

В блоке **Цветовой режим** можно задать цветовую схему  отображения значений (цвет, размер и расположение подписей на графике) выбрав режим: **Общий** (для всех элементов графика) или **Поэлементно** (для каждого элемента отдельно). 

#### Прореживание значений

Позволяет показывать значения через каждые N элементов, чтобы улучшить читаемость графика.


### Сортировка по значениям

![Сортировка по значениям](visualization-charts-stacked-sort.png)

Позволяет отсортировать данные по возрастанию или убыванию.  В случае, если на графике отображено более одного элемента, сортировка рассчитывается исходя из суммы элементов.


## Оси

### Базовые настройки (только двухосевая линейная диаграмма)

![Оси - Базовые настройки](visualization-charts-biaxial-line-osi-config-base.png)

### Надписи по оси X

![Надписи по оси X](visualization-charts-stacked-x-labels.png)

- Длина (px) - длина подписи в пикселях
- Размер (px) – размер шрифта подписи в пикселях
- Тип – размещение подписи. Выбор из следующих значений:
    - По горизонтали
    - По диагонали
    - По вертикали
- Перевернуть надписи – возможность изменить направление текста подписи. Доступно только при следующих типах надписей: **По диагонали** и **По вертикали**.
- Скрыть ось – возможность скрыть ось
- Многоточие при переполнении - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, будет заменена многоточием (по умолчанию эта функция включена);
- Перенос текста - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, переносится на следующую строку;

!!! note "Важно"
    Все параметры раздела **Надписи по оси X/Y**, кроме **Скрыть ось**, недоступны при первом открытии меню редактирования. Для того, чтобы иметь возможность изменять эти параметры, необходимо в разделе **Интервал осевых точек** выбрать режим редактирования **Пользовательский**.


### Интервал осевых точек

![Конфигурация - Оси - Интервал осевых точек](visualization-chart-gantt-osi-interval-tochek.png)

Позволяет задать тип отображения для каждой оси:

- Сохранить конец – отображать конечное наименование для ряда данных по оси
- Сохранить начало – отображать начальное наименование для ряда данных по оси
- Сохранить начало и конец – отображать начальное и конечное наименования для рядов данных по оси
- Пользовательский – задать интервал отображения наименований вручную, установив значение в поле **Число**.

### Разрядность

![Разрядность](visualization-charts-stacked-digits.png)

Позволяет настроить отображение формата числовых значений (1 000 000, 1 000К или 1M) как на осях, так и на самом графике, выбрав из выпадающего списка соответствующее значение - `Нет`, `К` или `М`.


### Границы

![Оси - Границы](visualization-chart-biaxial-osi-granicy.png)

Можно установить границы значений для осей, задав **Минимум** и **Максимум**

!!! note ""
    Если указать большее значение в поле **Минимум**, а меньшее значение в поле **Максимум**, то график приобретает **перевернутый (обратный) вид**.

### Элементы

![Оси - Элементы](visualization-charts-biaxial-osi-elementy.png)

В разделе можно задать выбрать **цвет** для серии данных из цветовой палитры.

## Сетка

![Конфигурация - Сетка](visualization-chart-gantt-setka.png)

### Тип линий

Выберите тип линий сетки на фоне графика. Возможные значения: 

- Без линий
- Сетка
- Горизонтальные линии
- Вертикальные линии

### Тип штриха

Выберите тип штриха, которым выполнены линии сетки. Возможные значения:

- Точки
- Штрих
- Длинный штрих
- Сплошная линия

### Цвет

Выберите из цветовой палитры цвет линий сетки.
