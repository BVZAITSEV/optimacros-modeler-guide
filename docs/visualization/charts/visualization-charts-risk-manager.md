# Анализ результатов РМ (Риск Менеджер)

Эта диаграмма предназначена для анализа распределения ряда чисел и позволяет оценить вероятность попадания значений в заданный диапазон (доверительный интервал). Она представляет собой столбцы, высота которых отражает частоту попадания значений числового куба в определённый диапазон, подобно дифференциальной кривой распределения.

Процесс построения диаграммы включает в себя несколько шагов:

- Весь диапазон значений от минимального до максимального делится на указанное в поле **Количество кластеров** число отрезков.
- Каждое значение из выбранного куба соотносится с границами этих отрезков, и подсчитывается количество значений, попавших в каждый из них (кластер).
- Каждый кластер на диаграмме представлен отдельным столбцом, высота которого соответствует количеству значений, попавших в соответствующий отрезок.

![Анализ результатов РМ](visualization-charts-risk-manager-overview.png) 

На оси X всегда отображаются границы кластеров, а на оси Y — количество значений, которые попали в каждый из них.

Чтобы узнать доверительную вероятность попадания в заданный доверительный интервал с помощью этой диаграммы, необходимо установить бегунки на желаемые значения. В центре будет указана вероятность оказаться внутри этого диапазона, а справа и слева — вероятности оказаться соответственно справа и слева от заданного интервала.


![Доверительная вероятность](visualization-charts-risk-manager-veroyatnost.png) 

Для построения диаграммы можно выбрать более одного куба. Чтобы выбрать нужный куб для отображения, воспользуйтесь фильтром диаграммы:

![Фильтр диаграммы](visualization-charts-risk-manager-filter.png)

Можно подсчитать количество строк и колонок, в которых содержатся нулевые значения. Для этого необходимо создать график, используя диапазон, содержащий только строки и колонки с нулями, исключая остальные значения. Границы диаграммы будут автоматически определены в диапазоне от 0 до 100, а диапазон будет разделён на количество кластеров, указанное пользователем.

Чтобы настроить график, откройте панель **Конфигурация графика**. В следующих разделах мы подробно рассмотрим каждую вкладку панели.


## Данные

### Базовые настройки


![Базовые настройки](visualization-charts-risk-manager-config-base.png)

#### Показывать всплывающую подсказку
Показывать подсказку при наведении курсора на элемент графика.

#### Настройки отображения элементов
Дать возможность установить максимальное количество отображаемых элементов и включить режим прореживания. После отметки этой опции появляется одноименный раздел конфигурации.


### Ориентир

![Ориентир](visualization-charts-kombo-orientir.png)

Указывает расположение данных (в строках или колонках).



### Настройки отображения элементов

![Настройки отображения элементов](visualization-charts-risk-manager-avtoprorezh.png)

График может отображать до 10 000 элементов. Вы можете настроить количество отображаемых данных. Если у вас мультикуб с большим количеством строк или столбцов, вы можете задавать суммарное количество элементов по всем кластерам. 

Следующий график построен на основе мультикуба с 10000 строками, суммарное количество элементов по всем кластерам будет равно 10000:

![Количество элементов 10000](visualization-charts-risk-manager-10000.png)

При изменении суммарного количества элементов по всем кластерам в строках на 500, получим следующий результат:

![Количество элементов 500](visualization-charts-risk-manager-500.png)

## Оси

### Разрядность

Позволяет настроить отображение формата числовых значений (1 000 000, 1 000К или 1M) как на осях, так и на самом графике, выбрав из выпадающего списка соответствующее значение - `Нет`, `К` или `М`.

![Разрядность](visualization-charts-risk-manager-razryadnost.png)

### Интервал осевых точек

![Конфигурация - Оси - Интервал осевых точек](visualization-charts-risk-manager-osi-interval-tochek.png)

Позволяет задать тип отображения для каждой оси:

- Сохранить конец – отображать конечное наименование для ряда данных по оси
- Сохранить начало – отображать начальное наименование для ряда данных по оси
- Сохранить начало и конец – отображать начальное и конечное наименования для рядов данных по оси
- Пользовательский – задать интервал отображения наименований вручную, установив значение в поле **Число**.

### Количество кластеров

Кластер — объединение нескольких однородных элементов, которое может рассматриваться как самостоятельная единица, обладающая определёнными свойствами, в данном случае - столбцы на графике с количеством элементов в определённом диапазоне.

![Конфигурация - Оси - Количество кластеров](visualization-charts-risk-manager-osi-klastery.png)


### Элементы


![Оси - Элементы](visualization-charts-risk-manager-osi-elementy.png)

В разделе можно выбрать цвет для серии данных из цветовой палитры.


## Сетка

![Конфигурация - Сетка](visualization-chart-gantt-setka.png)

### Тип линий

Выберите тип линий сетки на фоне графика. Возможные значения: 

- Без линий
- Сетка
- Горизонтальные линии
- Вертикальные линии

### Тип штриха

Выберите тип штриха, которым выполнены линии сетки. Возможные значения:

- Точки
- Штрих
- Длинный штрих
- Сплошная линия

### Цвет

Выберите из цветовой палитры цвет линий сетки.
