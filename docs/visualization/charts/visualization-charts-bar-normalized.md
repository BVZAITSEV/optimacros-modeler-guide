# Вертикальная столбчатая диаграмма в % / Горизонтальная столбчатая диаграмма в %

Нормированная столбчатая диаграмма позволяет наглядно представить значения в виде вертикальных или горизонтальных столбцов, разделённых на выделенные цветом части. Каждая из этих частей отражает вклад соответствующей величины в итоговое значение по определённому периоду или иному измерению.

Значения на диаграмме представлены в процентах, а высота всех столбцов одинакова и составляет 100%. 

![Вертикальная столбчатая диаграмма в %](visualization-charts-bar-normalized-vertical.png)

![Горизонтальная столбчатая диаграмма в %](visualization-charts-bar-normalized-horizontal.png)

Чтобы настроить график, откройте панель **Конфигурация графика**. В следующих разделах мы подробно рассмотрим каждую вкладку панели.

## Данные

### Базовые настройки


![Базовые настройки](visualization-charts-bar-config-base.png)

#### Исключить итоговые строки
Не показывать итоговые значения в строках.
#### Исключить итоговые колонки.
Не показывать итоговые значения в колонках.
#### Исключить пустые значения
Не показывать ряды без данных (с обрезанием графика).
#### Скрыть пустые значения
Не показывать нулевые значения (без обрезания графика).
#### Скрыть пустые области
Скрывает на графике пустые значения, расположенные в начале и в конце области построения. При этом нулевые значения, находящиеся внутри массива данных, остаются видимыми.

Чтобы скрыть пустые значения из легенды, отметьте опцию **Скрыть пустые значения**. В этом случае график сохранит сдвиг массива данных к началу координат.

#### Показывать всплывающую подсказку
Показывать подсказку при наведении курсора на элемент графика.

#### Показывать значения
Отображать значения для каждого ряда данных. После отметки этой опции появляется раздел конфигурации **Настройки отображения значений**.

#### Отобразить топ-элементы
Дать возможность задать наибольшее или наименьшее количество значений (из выбранных для построения графика), которые затем будут показаны на графике. После отметки этой опции появляется одноименный раздел конфигурации.



### Настройки отображения значений

![Настройки отображения значений](visualization-charts-bar-normalized-otobrazh-znach.png)

В блоке **Цветовой режим** можно задать цветовую схему  отображения значений (цвет, размер и расположение подписей на графике) выбрав режим: **Общий** (для всех элементов графика) или **Поэлементно** (для каждого элемента отдельно). 


#### Скрывать значения вне границ

Опция позволяет скрывать значения, выходящие за пределы графика.


### Ориентир

![Ориентир](visualization-charts-kombo-orientir.png)

Указывает расположение данных (в строках или колонках).


### Отобразить топ-элементы

![Отобразить топ-элементы](visualization-charts-stacked-top-elements.png)

С помощью этого функционала можно указать число максимальных или минимальных значений, которые будут отображаться на графике. Базовое значение поля Число настройки — 0, и функция активируется, если в поле указано другое число.

Настройка доступна как для столбцов, так и для строк. При изменении ориентира настройка топ-элементов сбрасывается.

Важно понимать, что логика работы этого функционала зависит от количества колонок или строк, используемых для построения графика:

- Если график строится на основе одной колонки или строки, за элемент принимается каждое значение.
- Если же график строится на основе нескольких колонок или строк, за элемент принимается сумма значений по выбранной колонке или строке (в зависимости от выбранного ориентира в настройках графика). Соответственно, сортировка по значениям в графике с топ-элементами, построенном на нескольких колонках или строках, будет происходить на основе суммы значений внутри элемента.

## Оси

### Надписи по оси X

![Надписи по оси X](visualization-charts-stacked-x-labels.png)

- Длина (px) - длина подписи в пикселях
- Размер (px) – размер шрифта подписи в пикселях
- Тип – размещение подписи. Выбор из следующих значений:
    - По горизонтали
    - По диагонали
    - По вертикали
- Перевернуть надписи – возможность изменить направление текста подписи. Доступно только при следующих типах надписей: **По диагонали** и **По вертикали**.
- Скрыть ось – возможность скрыть ось
- Многоточие при переполнении - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, будет заменена многоточием (по умолчанию эта функция включена);
- Перенос текста - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, переносится на следующую строку;

!!! note "Важно"
    Все параметры раздела **Надписи по оси X/Y**, кроме **Скрыть ось**, недоступны при первом открытии меню редактирования. Для того, чтобы иметь возможность изменять эти параметры, необходимо в разделе **Интервал осевых точек** выбрать режим редактирования **Пользовательский**.


### Интервал осевых точек

![Конфигурация - Оси - Интервал осевых точек](visualization-chart-gantt-osi-interval-tochek.png)

Позволяет задать тип отображения для каждой оси:

- Сохранить конец – отображать конечное наименование для ряда данных по оси
- Сохранить начало – отображать начальное наименование для ряда данных по оси
- Сохранить начало и конец – отображать начальное и конечное наименования для рядов данных по оси
- Пользовательский – задать интервал отображения наименований вручную, установив значение в поле **Число**.


### Элементы

![Оси - Элементы](visualization-charts-bar-normalized-osi-elementy.png)

В разделе можно задать выбрать **цвет** для серии данных из цветовой палитры.

## Легенда

### Базовые настройки

Можно снять отметку **Показывать легенду**, чтобы убрать легенду с графика.

### Расширенные настройки

Определяют позицию и  размер легенды, размер шрифта в ней, отступы и размер иконки:

![Легенда - Расширенные настройки](visualization-charts-pie-legenda-extended.png)

-  **Многоточие при переполнении** - если надпись превышает заданную длину, то часть, которая выходит за пределы, будет заменена многоточием (по умолчанию эта функция включена)
-  **Перенос текста** - если надпись превышает заданную длину, то часть, которая выходит за пределы, переносится на следующую строку

## Сетка

![Конфигурация - Сетка](visualization-chart-gantt-setka.png)

### Тип линий

Выберите тип линий сетки на фоне графика. Возможные значения: 

- Без линий
- Сетка
- Горизонтальные линии
- Вертикальные линии

### Тип штриха

Выберите тип штриха, которым выполнены линии сетки. Возможные значения:

- Точки
- Штрих
- Длинный штрих
- Сплошная линия

### Цвет

Выберите из цветовой палитры цвет линий сетки.
