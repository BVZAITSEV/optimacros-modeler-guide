# Комбинированный график

В комбинированном графике совмещены два или более типов графиков, что позволяет более эффективно оценивать данные, особенно если они сильно отличаются друг от друга. Вспомогательная ось, добавленная к такому графику, ещё больше облегчает восприятие информации.

![Комбинированный график](visualization-charts-kombo-overview.png) 

Чтобы настроить график, откройте панель **Конфигурация графика**. В следующих разделах мы подробно рассмотрим каждую вкладку панели.


![Комбинированный график](visualization-charts-kombo-configuration.png)

## Данные

### Базовые настройки


![Базовые настройки](visualization-charts-kombo-config-base.png)

#### Исключить итоговые строки
Не показывать итоговые значения в строках.
#### Исключить итоговые колонки.
Не показывать итоговые значения в колонках.
#### Исключить пустые значения
Не показывать ряды без данных (с обрезанием графика).
#### Скрыть пустые значения
Не показывать нулевые значения (без обрезания графика).
#### Скрыть пустые области
Скрывает на графике пустые значения, расположенные в начале и в конце области построения. При этом нулевые значения, находящиеся внутри массива данных, остаются видимыми.

![Скрыть пустые области](visualization-charts-kombo-hideemptyareas.gif)

Чтобы скрыть пустые значения из легенды, отметьте опцию **Скрыть пустые значения**. В этом случае график сохранит сдвиг массива данных к началу координат.

#### Показывать всплывающую подсказку
Показывать подсказку при наведении курсора на элемент графика.
#### Новые элементы - линии
Линейный вид графика будет автоматически выбран для новых элементов. Если график построен на мультикубе со справочником, состоящим из списка SKU, и опубликован на дашборд, то при добавлении нового SKU в справочник элемент будет отображаться на графике в виде столбца. При активной опции **Новые элементы – линии** новый элемент будет добавлен в виде линии.
#### Показывать значения
Отображать значения для каждого ряда данных. После отметки этой опции появляется раздел конфигурации **Настройки отображения значений**.
#### Настройки отображения элементов
Дать возможность установить максимальное количество отображаемых элементов и включить режим прореживания. После отметки этой опции появляется одноименный раздел конфигурации.
#### Настройки меток
Дать возможность настроить отображение на графике ряда данных логического формата (меток). После отметки этой опции появляется одноименный раздел конфигурации.
#### Отобразить топ-элементы
Дать возможность задать наибольшее или наименьшее количество значений (из выбранных для построения графика), которые затем будут показаны на графике. После отметки этой опции появляется одноименный раздел конфигурации.



### Настройки отображения значений

![Настройки отображения значений](visualization-charts-kombo-otobrazh-znach.png)

В блоке **Цветовой режим** можно задать цветовую схему  отображения значений (цвет, размер и расположение подписей на графике) выбрав режим: **Общий** (для всех элементов графика) или **Поэлементно** (для каждого элемента отдельно). 

Опция **Прореживание значений** позволяет указать число n и отображать подпись только для каждого n-го значения (число 0 отключает опцию).

### Настройки меток

![Метки на графике](visualization-charts-kombo-metki-grafik.png)

Метки выделяют значения изменением формы и цвета точек или проведением прямых линий.

![Настройки меток](visualization-charts-kombo-metki.png)

Для построения меток используется куб в логическом формате. Этот куб должен входить в состав мультикуба, на котором построен график, и быть выделен при построении вместе с остальными кубами. На графике возможны только две серии меток.

Метки отображаются только в том случае, если в настройках оси выбран тип элемента **Линия**. В этих же настройках есть возможность исключить логические кубы из легенды графика.

Необходимо выбрать серию меток (**Метки 1** или **Метки 2**). Затем для выбранной серии меток нужно указать следующее:

- **На основании куба** - выпадающий список из всех логических кубов в кубах, выбранных в мультикубе для построения графика
- **Тип меток** - возможные варианты **Точки** и **Линии**
- **Отображать на** - выпадающий список из доступных кубов, на которых будут отображаться метки. Для отображения меток на всех кубах нужно выбрать в выпадающем списке значение **Всех кубах**. НЕдоступен при выборе типа меток **Линии**, так как в этом случае данные отображается на всех кубах графика.
- **Форма меток** - доступные варианты зависят от выбранного типам меток. Для типа **Точки** доступны значения **Классическая**, **Квадратная** и **Объемная**. Для типа Линии доступны значения **Сплошная линия**, **Штрих** и **Длинный штрих**.


### Ориентир

![Ориентир](visualization-charts-kombo-orientir.png)

Указывает расположение данных (в строках или колонках).

### Укладка столбцов

Задает тип отображения столбцов. Возможные варианты:

- Кластерный
  ![Укладка столбцов - кластерный](visualization-charts-kombo-stolbec-klaster.png)

- Сложенный
  ![Укладка столбцов - сложенный](visualization-charts-kombo-stolbec-slozhen.png)

- Проценты
  ![Укладка столбцов - проценты](visualization-charts-kombo-stolbec-procenty.png)

Тип **Проценты** не доступен для графика, данные которого отображены в виде линий.


### Тип линий

Опция доступна пои наличии на графике серии данных, отображаемой в виде линии (указывается на вкладке **Оси->Элементы**). Возможные варианты:

- Ломаные
- Плавные

### Сортировка по значениям

Позволяет отсортировать данные по возрастанию или убыванию.  В случае, если на графике отображено более одного элемента, сортировка рассчитывается исходя из суммы элементов.


### Отобразить топ-элементы

С помощью этого функционала можно указать число максимальных или минимальных значений, которые будут отображаться на графике. Базовое значение поля Число настройки — 0, и функция активируется, если в поле указано другое число.

![Отобразить топ-элементы](visualization-charts-kombo-top-elements.png)

Настройка доступна как для столбцов, так и для строк. При изменении ориентира настройка топ-элементов сбрасывается.

Важно понимать, что логика работы этого функционала зависит от количества колонок или строк, используемых для построения графика:

- Если график строится на основе одной колонки или строки, за элемент принимается каждое значение.
- Если же график строится на основе нескольких колонок или строк, за элемент принимается сумма значений по выбранной колонке или строке (в зависимости от выбранного ориентира в настройках графика). Соответственно, сортировка по значениям в графике с топ-элементами, построенном на нескольких колонках или строках, будет происходить на основе суммы значений внутри элемента.

### Настройки отображения элементов (Автопрореживание)

![Настройки отображения элементов (Автопрореживание)](visualization-charts-kombo-avtoprorezh.png)

Комбинированный график может отображать до 10 000 элементов. Вы можете настроить количество отображаемых данных. Если у вас мультикуб с большим количеством строк или столбцов, вы можете выбрать желаемое количество элементов для показа и установить коэффициент прореживания для каждой категории (строк или столбцов).

![Настройки отображения элементов - Автопрореживание](visualization-charts-kombo-thinout.gif)

Функция **Автопрореживание** автоматически отключит процесс прореживания, если количество выбранных элементов мультикуба, по которым строится график, станет меньше установленного в параметре **Автопрореживание**. Это может произойти, например, при перестройке комбинированного графика на дашборде, если у вас настроен входящий контекст.

Кроме того, теперь вы можете указать общее количество элементов для всех кластеров.


## Оси

### Базовые настройки

- **Показать кубы** - отображать названия кубов на оси
- **Скрыть точки у линий** - не показывать точки на графике типа **Линия**

### Надписи по оси X

- Длина (px) - длина подписи в пикселях
- Размер (px) – размер шрифта подписи в пикселях
- Тип – размещение подписи. Выбор из следующих значений:
    - По горизонтали
    - По диагонали
    - По вертикали
- Перевернуть надписи – возможность изменить направление текста подписи. Доступно только при следующих типах надписей: **По диагонали** и **По вертикали**.
- Скрыть ось – возможность скрыть ось
- Многоточие при переполнении - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, будет заменена многоточием (по умолчанию эта функция включена);
- Перенос текста - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, переносится на следующую строку;

!!! note "Важно"
    Все параметры раздела **Надписи по оси X/Y**, кроме **Скрыть ось**, недоступны при первом открытии меню редактирования. Для того, чтобы иметь возможность изменять эти параметры, необходимо в разделе **Интервал осевых точек** выбрать режим редактирования **Пользовательский**.


### Интервал осевых точек

![Конфигурация - Оси - Интервал осевых точек](visualization-chart-gantt-osi-interval-tochek.png)

Позволяет задать тип отображения для каждой оси:

- Сохранить конец – отображать конечное наименование для ряда данных по оси
- Сохранить начало – отображать начальное наименование для ряда данных по оси
- Сохранить начало и конец – отображать начальное и конечное наименования для рядов данных по оси
- Пользовательский – задать интервал отображения наименований вручную, установив значение в поле **Число**.

### Разрядность

Позволяет настроить отображение формата числовых значений (1 000 000, 1 000К или 1M) как на осях, так и на самом графике, выбрав из выпадающего списка соответствующее значение - `Нет`, `К` или `М`.

### Заполнение по оси X

![Конфигурация - Оси - Заполнение по оси X](visualization-chart-kombo-osi-zapolnenie.png)

Позволяет задать отступы слева и справа от оси, в процентах от ширины графика. Допустимые значения от 0 до 25 %.


### Границы

![Оси - Границы](visualization-chart-kombo-osi-granicy.png)

Можно установить следующие значения:

  - границы значений для оси, задав **Минимум** и **Максимум**
  - отдельные границы для графиков с двумя осями (**Границы Справа** и **Границы Слева**), задав **Минимум** и **Максимум** для правой и левой осей соответственно, выбрав предварительно правую ось в разделе **Элементы**;

!!! note ""
    Если указать большее значение в поле **Минимум**, а меньшее значение в поле **Максимум**, то график приобретает **перевернутый (обратный) вид**.

### Элементы


![Оси - Элементы](visualization-charts-kombo-osi-elementy.png)

В разделе можно задать следующее:

- **Тип** - тип отображения для каждого ряда данных. Возможны следующие варианты: `Столбец`, `Линия`, `Исключить`
- **Цвет** - выбрать цвет для серии данных из цветовой палитры
- **Правая ось** - можно назначить вспомогательную ось для серии данных, поставив отметку в этом поле

!!! note ""
    В случае, когда переключены на Правую ось все элементы, то ось слева будет спрятана, а график станет правосторонне-ориентированным.

## Сетка

![Конфигурация - Сетка](visualization-chart-gantt-setka.png)

### Тип линий

Выберите тип линий сетки на фоне графика. Возможные значения: 

- Без линий
- Сетка
- Горизонтальные линии
- Вертикальные линии

### Тип штриха

Выберите тип штриха, которым выполнены линии сетки. Возможные значения:

- Точки
- Штрих
- Длинный штрих
- Сплошная линия

### Цвет

Выберите из цветовой палитры цвет линий сетки.
