# Диаграмма Ганта

Диаграмма Ганта используется как инструмент для отображения хода выполнения запланированных работ с течением времени.

![Диаграмма Ганта](visualization-charts-gantt.png)

## Мультикуб для построения диаграммы

Для построения диаграммы Ганта необходим мультикуб аналогичный показанному на следующей картинке:

![Мультикуб для построения диаграммы Ганта](visualization-chart-gantt-multicube.png)

Мультикуб построен на пользовательском справочнике **Задачи проекта** и включает следующие кубы:

- **Начало** – куб в формате Date, обозначающий начало этапа проекта. **Обязательный куб**.
- **Окончание** – куб в формате Date, обозначающий окончание этапа проекта. **Обязательный куб**.
- **Подпись** - куб в текстовом формате, содержит подписи к задачам на диаграмме. Необязательный куб.
- **Этап** - куб с текстом для отображения на всплывающих подсказках. Необязательный куб.
- **Цвет HEX** – куб в текстовом формате с данными в виде HEX-кода. Куб позволяет выбрать любой цвет бара на диаграмме. Необязательный куб.
- **Готовность** – куб в процентном числовом формате. Содержит статус выполнения текущего этапа на диаграмме. Необязательный куб.
- **Предшественник** - куб в формате измерения, на элементах которого построена диаграмма. Необходим для отрисовки зависимостей. Необязательный куб.
- **Тип зависимости** - куб в текстовом формате. Содержит код типа зависимости. Необязательный куб.
- **Тип стрелок** - куб в текстовом формате. Устанавливает вид стрелок и линий, которыми отображаются зависимости. Необязательный куб.
- **Цвет стрелок** - куб в текстовом формате с данными в виде HEX-кода. Устанавливает цвет стрелок и линий зависимостей. Необязательный куб.
- **Событие дата_1** – куб в формате даты. содержит дату первой вехи на диаграмме. Необязательный куб.
- **Событие текст_1** – куб в текстовом формате, содержит текст для первой вехи на диаграмме. Необязательный куб.
- **Событие дата_2** – куб в формате даты. содержит дату второй вехи на диаграмме. Необязательный куб.
- **Событие текст_2** – куб в текстовом формате, содержит текст для второй вехи на диаграмме. Необязательный куб.


Названия кубов могут быть любыми, нужный куб указывается при конфигурации графика.

Чтобы настроить график, откройте панель **Конфигурация графика**. В следующих разделах мы подробно рассмотрим каждую вкладку панели.

## Вкладка Данные

![Диаграмма Ганта - Конфигурация - Данные](visualization-chart-gantt-dannye.png)

### Начало и конец бара на основании

Для начала построения диаграммы Ганта необходимо в разделе **Начало и конец бара на основании** указать кубы, в которых задаются даты начала и окончания задач:

![Диаграмма Ганта - Конфигурация - Начало](visualization-chart-gantt-dannye-nachalo.png)

### Элементы начала и конца бара

Позволяют установить для начала и конца бара следующие элементы:

- прямоугольник
- стрелка
- полукруг

!!! note "Важно"
    Однодневное событие, то есть событие у которого дата начала равна дате конца, отображается в виде ромба.

### Цвет бара на основании

Позволяет задать цвет бара с помощью куба в текстовом формате, содержащем значение цвета в HEX формате. В мультикубе примера это куб **Цвет HEX**.

### Подписи на основании кубов

![Диаграмма Ганта - Конфигурация - Подписи](visualization-chart-gantt-dannye-podpis.png)

Позволяет выбрать куб любого формата или справочник, расположенный в строках мультикуба, в качестве подписи бара.

Раздел включает три выпадающих списка, позволяющих независимо установить подпись в трех следующих позициях:

 - внутри бара
 - слева от бара
 - справа от бара

### Готовность, &percnt;

 Поставьте отметку в поле **Готовность, &percnt;** чтобы открыть раздел **Готовность, &percnt;** и задать следующие параметры:

- **Источник** – куб в процентном формате, содержащий значения готовности задачи
- **Тип индикатора**– внешний вид индикатора готовности на баре, возможен выбор из двух вариантов: 
    - столбец
    - линия
- **Цвет** – позволяет выбрать цвет для индикатора выполнения

![Диаграмма Ганта - Конфигурация - Готовность](visualization-chart-gantt-dannye-gotovnost.png)


### Зависимость

Зависимости показывают, как задачи связаны друг с другом и в каком порядке они должны выполняться. На диаграмме Ганта зависимость отображается в виде линии со стрелкой, соединяющей начало/конец одного бара с началом/концом другого.

![Диаграмма Ганта - Конфигурация - Зависимость](visualization-chart-gantt-dannye-zavisimost.png)

!!! note "Важно"
    Зависимости начнут отображаться на графике только после выбора куба для отображения подписей (**Подписи на основании кубов**)

#### Предшественник

**Предшественник на основании куба** - необходимо выбрать куб в формате справочника, на котором построен исходный мультикуб. Значение куба - предшественник текущего элемента, то есть элемент, от которого отображается зависимость текущего элемента.

#### Тип зависимости

**Тип зависимости на основании куба** - необходимо выбрать куб в текстовом формате, значения которого определяют тип зависимости.

Допустимые типы зависимостей представляют собой комбинации двух символов:

- FS (Finish to Start): стрелка направлена от конца предшествующего бара к началу зависимого бара
- SS (Start to Start): стрелка направлена от начала предшествующего бара к началу зависимого бара
- FF (Finish to Finish): стрелка направлена от конца предшествующего бара к концу зависимого бара
- SF (Start to Finish): стрелка направлена от начала предшествующего бара к концу зависимого бара

![Типы зависимостей](visualization-chart-gantt-dannye-zavisimost-tipy.png)

#### Тип стрелок 

- **Тип стрелок на основании куба** - необходимо выбрать куб в текстовом формате, значения которого определяют тип стрелок.

Допустимые типы стрелок представляют собой следующие строки:

- Solid - сплошная линия
- Dot - точки
- Dash - тире
- Long Dash - длинное тире

Если тип стрелки не указан, используется Solid - сплошная линия.

#### Цвет стрелок

- **Цвет стрелок на основании куба** - необходимо выбрать текстовый куб, значения которого определяют цвет в HEX формате.

### Всплывающая подсказка

![Всплывающая подсказка](visualization-chart-gantt-dannye-podskazka.png)

Если поставить отметку **Показывать всплывающую подсказку**, откроется раздел  **Всплывающая подсказка на основании**, в котором можно указать до трех текстовых кубов для отображения трех строк в подсказке:

![Всплывающая подсказка на графике](visualization-chart-gantt-dannye-podskazka-na-grafike.png)


## Оси

![Диаграмма Ганта - Конфигурация - Оси](visualization-chart-gantt-osi.png)

### Позиция оси X

Можно выбрать следующее расположение оси X:

- Сверху
- Снизу

### Надписи по оси Y

- Длина (px) - длина подписи в пикселях
- Размер (px) – размер шрифта подписи в пикселях
- Тип – размещение подписи. Выбор из следующих значений:
    - По горизонтали
    - По диагонали
    - По вертикали
- Перевернуть надписи – возможность изменить направление текста подписи. Доступно только при следующих типах надписей: **По диагонали** и **По вертикали**.
- Скрыть ось – возможность скрыть ось
- Многоточие при переполнении - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, будет заменена многоточием (по умолчанию эта функция включена);
- Перенос текста - если надпись превышает заданную длину, установленную в поле Длина (px), то часть, которая выходит за пределы, переносится на следующую строку;

!!! note "Важно"
    Все параметры раздела **Надписи по оси X/Y**, кроме **Скрыть ось**, недоступны при первом открытии меню редактирования. Для того, чтобы иметь возможность изменять эти параметры, необходимо в разделе **Интервал осевых точек** выбрать режим редактирования **Пользовательский**.

### Формат даты оси Х

Позволяет выбрать в выпадающем списке нужный формат:

- Европейский формат даты
- Американский формат даты
- Года
- Полугодия
- Кварталы
- Месяцы
- Дни

### События (вехи)

![Диаграмма Ганта - Конфигурация - Оси - События (вехи)](visualization-chart-gantt-osi-sobytija.png)

Можно настроить до четырех событий (вех) на диаграмме. Для каждого события требуются свои кубы даты и текста.

Необходимо задать следующие параметры:

- **Выбор события**– необходимо выбрать одно из четырех событий для его дальнейшей настройки.
- **Дата на основании куба** – нужно выбрать куб в формате даты, определяющий дату события. Дата берется из самого верхнего по иерархии элемента измерения, из первого в списке, если их в кубе несколько.
- **Текст на основании куба** – нужно выбрать куб в текстовом формате, содержащий описание события. Текст берется из самого верхнего по иерархии элемента измерения, из первого в списке, если их в кубе несколько.

    !!! note "Важно"
        Необходимо, чтобы самый верхний элемент куба для отображения текста содержал текст, то есть был непустым.
    
- **Тип штриха** – вид линии вехи на диаграмме. Возможен выбор из следующих вариантов: 
    - Точки
    - Штрих
    - Длинный штрих
    - Сплошная линия
- **Позиция текста** – позволяет выбрать место расположения текста из параметра **Текст на основании куба**. Возможны следующие варианты: 
    - Сверху справа
    - Сверху слева
    - Снизу справа
    - Снизу слева
- **Длина текста** – позволяет изменять длину текста в пределах от 0 до 500 пикселей.
- **Цвет линии**– позволяет изменять цвет линии вехи.

### Интервал осевых точек

![Диаграмма Ганта - Конфигурация - Оси - Интервал осевых точек](visualization-chart-gantt-osi-interval-tochek.png)

Позволяет задать тип отображения для каждой оси:

- Сохранить конец – отображать конечное наименование для ряда данных по оси
- Сохранить начало – отображать начальное наименование для ряда данных по оси
- Сохранить начало и конец – отображать начальное и конечное наименования для рядов данных по оси
- Пользовательский – задать интервал отображения наименований вручную, установив значение в поле **Число**.

### Заполнение по оси X

![Диаграмма Ганта - Конфигурация - Оси - Заполнение по оси X](visualization-chart-gantt-osi-zapolnenie.png)

Позволяет задать отступы слева и справа от оси, в процентах от ширины графика. Допустимые значения от 5 до 25 %.

## Сетка

![Конфигурация - Сетка](visualization-chart-gantt-setka.png)

### Тип линий

Выберите тип линий сетки на фоне графика. Возможные значения: 

- Без линий
- Сетка
- Горизонтальные линии
- Вертикальные линии

### Тип штриха

Выберите тип штриха, которым выполнены линии сетки. Возможные значения:

- Точки
- Штрих
- Длинный штрих
- Сплошная линия

### Цвет

Выберите из цветовой палитры цвет линий сетки.
