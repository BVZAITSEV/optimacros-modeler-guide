# Графики (Визуальные объекты)

## Выбор данных

Графики могут быть построены только на основе числовых данных, которые расположены в двумерной проекции мультикуба, то есть в табличном представлении. 

Для создания графика необходимо выделить несколько последовательно расположенных областей данных. Если выделить произвольные области данных, удерживая клавишу  ++ctrl++  , в построении графика будет участвовать только первая выделенная область. Если требуемые области не граничат между собой, можно создать упрощенное **представление мультикуба** с помощью команд [Скрыть][cmd-view-hide] или [Показать][cmd-view-show], в котором можно будет выделить непрерывную область данных.

## Выбор вида графика

После выделения области данных необходимо воспользоваться кнопкой панели инструментов ![](icon-toolbar-visual-objects.png){ .off-glb } **Визуальные объекты** для выбора вида графика в выпадающем списке. ## Настройка графика

При выборе вида графика открывается модальное окно, которое включает график, панель инструментов и панель **Конфигурация графика**:

![Настройка графика](visualization-charts-chart-area.png)

Чтобы настроить параметры графика, обратитесь к панели **Конфигурация графика**. Эта панель содержит несколько вкладок, которые различаются для разных типов графиков. В качестве примера приведем вкладки панели конфигурации для комбинированного графика:

![Вкладки панели конфигурации для комбинированного графика](visualization-charts-configuration-panel.png)

На этом этапе можно изменить вид графика, используя кнопку панели инструментов ![](icon-toolbar-visual-objects.png){ .off-glb } **Визуальные объекты** и выбрав новый вид из выпадающего списка.

Чтобы обновить данные графика, нажмите ![](icon-toolbar-refresh.png){ .off-glb } **Обновить**  на панели инструментов. 

## Публикация графика

Чтобы сохранить построенный график, необходимо опубликовать его на ранее созданный дашборд или контекстную таблицу. Для этого перейдите в меню панели инструментов графика **Представление -> Опубликовать на Дашборд** и выберите дашборд (или **Представление -> Опубликовать на Контекстную Таблицу** и выберите контекстную таблицу).

Все возможности конфигурации графика сохраняются на карточке дашборда или контекстной таблицы в режиме редактирования.
