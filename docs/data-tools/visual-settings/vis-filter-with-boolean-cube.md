# Фильтрация по логическому кубу

Фильтрация по логическому кубу — это эффективный способ отобразить в справочнике только те элементы, значения которых в сопоставимом по измерению логическом кубе равны TRUE. В качестве логического куба можно использовать логическое свойство того же справочника.

## Применить фильтр

Чтобы отфильтровать элементы справочника по логическому кубу, достаточно воспользоваться пунктом контекстного меню **Отфильтровать по булеан кубу**, щелкнув правой кнопкой мыши по заголовку элемента справочника:

![Фильтрация по логическому кубу - меню](filter-with-boolean-cube-01-menu.png)

В открывшемся диалоговом окне на вкладке **Основные** представлены справочники и их свойства в логическом формате, доступные для фильтрации. Также отображены все мультикубы с сопоставимыми измерениями, а в квадратных скобках указано название соответствующего измерения, по которому также можно фильтровать элементы данного справочника.

![Отфильтровать по булеан Кубу - Диалог - закладка Основные](filter-with-boolean-cube-02-dialog.png)

На вкладке **Расширенные** вы можете отключить настройку **Зависимый контекст**, если необходимо ограничить возможность использования контекста в фильтрации для связанных контекстом таблиц (опубликованных на дашбордах или в контекстных таблицах). Для этого уберите галочку из поля **Применять Зависимый контекст**. Поле **Лимит выборки** задает допустимое количество элементов при фильтрации (от 1000 до 10000). Обратите внимание, что отфильтровать можно только первые 100 тысяч элементов, остальные игнорируются.

![Отфильтровать по булеан Кубу - Диалог - закладка Расширенные](filter-with-boolean-cube-03-dialog.png)


## Снять фильтр

Чтобы снять фильтр, откройте диалоговое окно и снимите выбор с ранее выбранного логического куба.

## Сохранить настройки

Чтобы настройки фильтрации сохранились при следующем открытии справочника, рекомендуется сохранить представление с помощью кнопки ![](icon-toolbar-save.png){ .off-glb } на панели инструментов или через пункт меню **Представление» -> Сохранить/Сохранить как**.

При необходимости параметры фильтрации можно скопировать в формате JSON:


![Параметры фильтрации можно скопировать в формате JSON](filter-with-boolean-cube-04-json-copy.png)

## Использовать настройки

Сохраненные настройки в формате JSON можно привязать к пользовательской кнопке или кнопке, опубликованной на дашборде. Для этого выполните следующие шаги:

- Откройте настройки кнопки
- В настройках кнопки на вкладке **По нажатию** выберите тип **Фильтровать по**.
- Скопированный код вставьте в поле JSON в интеграционной форме на вкладке **Расширенные**.
- Отметьте галочкой пункт **Использовать JSON в интеграционной форме**.
- Сохраните настройки, нажав кнопку **ПРИМЕНИТЬ**.

![Настройка пользовательской кнопки](filter-with-boolean-cube-customize-button.png)
