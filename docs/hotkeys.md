# Горячие клавиши

!!! note "Важно"
    Используйте `Alt` и `Shift` с левой стороны клавиатуры.

| Сочетание клавиш | Действие | Контекст |
| :---: | --- | --- |
| [Tab](#){ .md-button .md-button-keycombination} | переход слева направо | интерфейсные элементы системы |
| [Shift + Tab](#){ .md-button .md-button-keycombination} | переход справа налево| интерфейсные элементы системы |
| [Ctrl + Q](#){ .md-button .md-button-keycombination} | вызов окна [Содержимое модели](model-contents-dialog.md) | рабочее пространство модели |
| [Alt + Shift + L](#){ .md-button .md-button-keycombination} | переключение языков интерфейса (английский-немецкий-русский)  | рабочее пространство модели |
| [Ctrl + S](#){ .md-button .md-button-keycombination} | создание резервной копии модели | рабочее пространство модели |
| [Ctrl + E](#){ .md-button .md-button-keycombination} | экспорт модели | рабочее пространство модели |
| [Ctrl + Shift + E](#){ .md-button .md-button-keycombination} | экспорт последней резервной копии модели (или экспорт модели при отсутствии резервной копии) | рабочее пространство модели  |
| [F9](#){ .md-button .md-button-keycombination} | пересчет модели | рабочее пространство модели |
| [Ctrl + F9](#){ .md-button .md-button-keycombination} | перезапуск модели | рабочее пространство модели |
| [Ctrl](#){ .md-button .md-button-keycombination} | позволяет выделить несколько ячеек таблицы | таблица |
| [Home](#){ .md-button .md-button-keycombination} | перемещение в начало таблицы по вертикали, сохраняя текущее выделение | таблица |
| [End](#){ .md-button .md-button-keycombination} | перемещение в конец таблицы по вертикали, сохраняя текущее выделение | таблица |
| [PgUp](#){ .md-button .md-button-keycombination} | перемещение на один экран вверх, сохраняя текущее выделение | таблица |
| [PgDn](#){ .md-button .md-button-keycombination} | перемещение на один экран вниз, сохраняя текущее выделение | таблица |
| [Shift + Home](#){ .md-button .md-button-keycombination} | выделение от текущего положения до верхнего края таблицы  | таблица |
| [Shift + End](#){ .md-button .md-button-keycombination} | выделение от текущего положения до нижнего края таблицы | таблица |
| [Shift + PgUp](#){ .md-button .md-button-keycombination} | выделение от текущего положения на один экран вверх  | таблица |
| [Shift + PgDn](#){ .md-button .md-button-keycombination} | выделение от текущего положения на один экран вниз | таблица |
| [Shift + прокрутка](#){ .md-button .md-button-keycombination} | перемещение в таблице по горизонтали | таблица |
| [Alt + 1](#){ .md-button .md-button-keycombination} | переключение между режимом редактирования и табличным видом мультикуба | таблица |
| [Alt + Home](#){ .md-button .md-button-keycombination} | перемещение в начало таблицы по горизонтали, сохраняя текущее выделение | таблица |
| [Alt + End](#){ .md-button .md-button-keycombination} | перемещение в конец таблицы по горизонтали, сохраняя текущее выделение | таблица |
| [Alt + PgUp](#){ .md-button .md-button-keycombination} | перемещение в таблице по горизонтали на один экран вправо, сохраняя текущее выделение  | таблица |
| [Alt + PgDn](#){ .md-button .md-button-keycombination} | перемещение в таблице по горизонтали на один экран влево, сохраняя текущее выделение | таблица |
| [Alt + Shift + PgUp](#){ .md-button .md-button-keycombination} | выделение от текущего положения на один экран влево | таблица |
| [Alt + Shift + PgDn](#){ .md-button .md-button-keycombination} | выделение от текущего положения на один экран вправо | таблица |
| [Alt + Shift + Home](#){ .md-button .md-button-keycombination} | выделение от текущего положения до правого края таблицы  | таблица |
| [Alt + Shift + End](#){ .md-button .md-button-keycombination} | выделение от текущего положения до левого края таблицы | таблица |
| [Delete](#){ .md-button .md-button-keycombination} | очистка значений выделенных ячеек | таблица |
| [Delete + Backspace ](#){ .md-button .md-button-keycombination} | установка значений `FALSE` в выделенные ячейки формата Boolean | таблица |
| [Enter](#){ .md-button .md-button-keycombination} | переход на ячейку ниже | таблица |
| [Enter](#){ .md-button .md-button-keycombination} | установка значений `TRUE` в выделенные ячейки формата Boolean | таблица |
| [Y](#){ .md-button .md-button-keycombination} | установка значений `TRUE` в выделенные ячейки формата Boolean | таблица |
| [N](#){ .md-button .md-button-keycombination} | установка значений `FALSE` в выделенные ячейки формата Boolean | таблица |
| [Q](#){ .md-button .md-button-keycombination} | инвертирование значений в выделенных ячейках формата Boolean  | таблица |
| [N](#){ .md-button .md-button-keycombination} | установка прав доступа `Nоne` в выделенных ячейках  | <term:МДП> |
| [R](#){ .md-button .md-button-keycombination} | установка прав доступа `Read` в выделенных ячейках | <term:МДП> |
| [W](#){ .md-button .md-button-keycombination} | установка прав доступа `Write` в выделенных ячейках | <term:МДП> |
| [F](#){ .md-button .md-button-keycombination} | установка роли `Full Access` в выделенных ячейках | <term:МДП> |
| [Y](#){ .md-button .md-button-keycombination} | установка роли `Full Access` в выделенных ячейках | <term:МДП> |
| [N](#){ .md-button .md-button-keycombination} | установка роли `No Access` в выделенных ячейках | <term:МДП> |
| [Delete](#){ .md-button .md-button-keycombination} | установка роли `No Access` в выделенных ячейках | <term:МДП> |
| [Backspace](#){ .md-button .md-button-keycombination} | установка роли `No Access` в выделенных ячейках | <term:МДП> |
