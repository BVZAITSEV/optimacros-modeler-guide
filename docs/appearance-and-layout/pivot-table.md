# Сводная таблица

Сводная таблица позволяет изменить вид мультикуба путем перемещения измерений в строки, в столбцы и в фильтры.

Для вызова окна диалога сводной таблицы нажмите кнопку ![](icon-toolbar-pivot-table.png){ .off-glb } на панели инструментов табличного представления мультикуба.

![Сводная таблица](pivot-table.png)

## Настройка вида мультикуба

Выберите измерение и перетащите его в одно из трех полей:

- Строки – чтобы элементы измерения в списке отображались в левой части таблицы в виде заголовков строк.
- Колонки – чтобы элементы измерения в списке отображались в верхней части таблицы в виде заголовков столбцов.
- Фильтры – чтобы элементы измерения были в виде выпадающего списка над таблицей.

Порядок расположения измерений мультикуба можно задать перетащив измерение в начало, конец или середину соответствующего поля.

Нажмите **OK** для применения изменений к мультикубу.

!!! note "Важно"
    Чтобы изменения остались при следующем открытии мультикуба, необходимо сохранить представление с помощью кнопки ![](icon-toolbar-save.png){ .off-glb } на панели инструментов или выбрав пункт меню **Представление › Сохранить/Сохранить как**.

При нажатии на три точки возле наименования измерения доступны дополнительные опции:

## Опция Открыть Измерение

![Опция Открыть Измерение](pivot-table-open-dimension.png)

Через пункт меню Открыть Измерение можно перейти напрямую к измерению, его выборкам или свойствам.

## Опция Скопировать в буфер обмена

Через пункт меню **Скопировать в буфер обмена** доступны часто используемые вариации формул с использованием наименования измерения для копирования в буфер обмена и последующей вставки в формульную строку:

- '*Наименование измерения*'
- ITEM('*Наименование измерения*')
- PARENT(ITEM('*Наименование измерения*'))

![Опция Скопировать в буфер обмена](pivot-table-copy-to-clipboard.png)

## Опция Выбрать для формулы

При работе в [редакторе формул](formula-editor.md) и открытии сводной таблицы вместо пункта меню **Скопировать в буфер обмена** появляется пункт **Выбрать для формулы**.

![Опция Выбрать для формулы](pivot-table-select-for-formula.png)

После того как вы выберете вариант формулы, она автоматически будет вставлена в строку формул.
