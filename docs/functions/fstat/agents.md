# AGENTS
Функция определяет количество серверов (агентов обслуживания) необходимых для достижения SLA (Service Level Agreement – соглашение об уровне обслуживания) при заданном целевом времени ответа, скорости поступления запросов и средней продолжительности обработки запросов.

## Синтаксис

AGENTS(X, ERLANGC_SLA(NUM_ARG, T, Y, Z))



## Аргументы
X, T, Y, Z - любое выражение возвращающее Число/Number

- X – SLA, согласованный уровень обслуживания;
- T - целевое время ответа;
- Y - скорость поступления запросов;
- Z - средняя продолжительность обработки запроса;
- NUM_ARG – параметр программно определяемый перебором.


## Возвращаемое значение

Числовой формат (Число/Процент)


## Эквивалент в Excel

нет

## Особенности AGENTS

Функция AGENTS рассчитывается на основе функции [ERLANGC_SLA](erlangc_sla.md). Параметр ё определяется перебором таким образом, чтобы функция [ERLANGC_SLA](erlangc_sla.md), рассчитанная с подобранным аргументом, вернула значение равное аргументу `X` (согласованный уровень обслуживания) при минимальном значении параметра `NUM_ARG`.

В аргументах целевого времени отклика, скорости поступления и средней продолжительности не обязательно использовать конкретную единицу времени. Например, они могут быть выражены в секундах или минутах. Однако все три аргумента должны использовать одну и ту же единицу времени.


## Пример

![Agents пример](f-agents.png)

Рассмотрим мультикуб, в столбцах которого находится справочник `Колл-центры`, а в строках кубы с аргументами функции:

- соглашение об уровне обслуживания
- целевое время ответа
- скорость поступления запросов
- средняя продолжительность

Количество агентов будет рассчитываться по формуле:

```
AGENTS('Соглашение об уровне обслуживания', ERLANGC_SLA(NUM_ARG, 'Целевое время ответа', 'Скорость поступления запросов', 'Средняя продолжительность'))
```

В кубе `Обновленное количество агентов` укажем значение изменения уровня обслуживания и рассчитаем обновленное количество агентов по формуле:


```
AGENTS('Соглашение об уровне обслуживания' + 'Изменение соглашения об уровне обслуживания', ERLANGC_SLA(NUM_ARG, 'Целевое время ответа', 'Скорость поступления запросов', 'Средняя продолжительность'))
```
