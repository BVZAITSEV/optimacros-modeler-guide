# ERLANGC_SLA

Функция определяет процент запросов (SLA – Service Level Agreement – соглашение об уровне обслуживания), обработка которых будет начата до истечения целевого времени ответа при заданном количестве серверов (агентов обслуживания), скорости поступления запросов и средней продолжительности обработки запросов.



## Синтаксис

ERLANGC_SLA(X, T, Y, Z)



## Аргументы
Любое выражение возвращающее Число/Number:

- X: запланированное количество агенто;
- T: целевое время ответа
- Y: скорость поступления запросов
- Z: средняя продолжительность


## Возвращаемое значение

Числовой формат (Число/Процент)


## Эквивалент в Excel

нет


## Формула расчета ERLANGC_SLA

ERLANGC_SLA рассчитывается на основе функции [ERLANGC](erlangc.md).

Общая формула расчета ERLANGC_SLA:

![Общая формула расчета ERLANGC_SLA](f-erlang_sla-formula.png)
при SLA ≠ 1

Где:

- х — количество агентов
- a — скорость поступления запросов, умноженная на среднюю продолжительность звонка (y*z),
- t – целевое время ответа.



Функция возвращает `NaN`, если количество агентов равно 0 или один из аргументов функции равен `NaN`.


## Пример

Рассмотрим мультикуб, в столбцах которого находится справочник `Колл-центры`, а в строках кубы с аргументами функции:

- запланированное количество агентов
- целевое время ответа
- скорость поступления запросов
- средняя продолжительность

Процент запросов, отвеченных до истечения целевого времени ответа, будет рассчитываться по формуле:

```
ERLANGC_SLA('Запланированное количество агентов', 'Целевое время ответа', 'Скорость поступления запросов', 'Средняя продолжительность').
```

В кубе `Изменение целевого времени ответа` укажем значение изменения времени ответа и рассчитаем обновленный процент отвеченных вызовов по формуле:

```
ERLANGC_SLA('Запланированное количество агентов', 'Целевое время ответа' + 'Изменение целевого времени ответа', 'Скорость поступления запросов', 'Средняя продолжительность')
```
