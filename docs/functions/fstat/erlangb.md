# ERLANGB

Функция определяет вероятность блокировки запроса при заданном количестве серверов (агентов обслуживания), скорости поступления запросов и средней продолжительности обработки запросов.

Различие [ERLANGC](erlangc.md) и `ERLANGB` состоит в том, что функция [ERLANGC](erlangc.md) рассчитывает вероятность, с которой при заданных условиях позвонившему придется подождать ответа оператора, а функция `ERLANGB` рассчитывает вероятность того, что позвонивший не дождется ответа.

## Синтаксис

ERLANGB(X,Y,Z)

## Аргументы
- X: любое выражение возвращающее Число/Number
- Y: любое выражение возвращающее Число/Number
- Z: любое выражение возвращающее Число/Number


## Возвращаемое значение

Числовой формат (Число/Number)

## Эквивалент в Excel

нет

## Формула расчета ERLANGB

![Формула расчета ERLANGB](f-erlangb-formula.png)

Где:

- х — количество агентов
- y — интервал между звонками
- z — средняя продолжительность звонка
- a — предполагаемая общая загрузка (y*z)

Функция возвращает `NaN`, если количество агентов  равно 0 или один из аргументов функции равен NaN.

## Пример

Cравним значения функций [ERLANGC](erlangc.md) и функции `ERLANGB` для одинаковых аргументов:

![Cравним значения функций ERLANGC и функции ERLANGB для одинаковых аргументов](f-erlangb-start.png)

Добавим куб `Дополнительные агенты`, влияющий на аргумент `Количество агентов`, и пересчитаем вероятности:

```
ERLANGB('Запланированное количество агентов' + 'Дополнительные агенты', 'Скорость поступления запросов', 'Средняя продолжительность выполнения запросов')
```
