# NOT 
Изменяет значение FALSE на TRUE, а TRUE на FALSE. 

## Синтаксис

NOT(x) 

## Аргументы

- x: значение или выражение, результатом которого является TRUE или FALSE. 

## Возвращаемое значение 

TRUE или FALSE (Логический формат) 

## Эквивалент в Excel

НЕ / NOT 

## Пример

NOT(a > 1500)
