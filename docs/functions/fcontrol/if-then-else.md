# IF THEN ELSE

Проверяет логическое выражение и возвращает одно из двух значений в зависимости от результата проверки (истина или ложь). 

## Синтаксис 

**IF** *x* **THEN** *y* **ELSE** *z* 

## Аргументы 

- x: выражение, дающее при вычислении `TRUE` или `FALSE`
- y: результат, если логический_аргумент = TRUE. Значение в форматах Number, Boolean, List, Text, Time Period
- z: результат, если логический_аргумент = FALSE. Значение в форматах Number, Boolean, List, Text, Time Period. 

## Возвращаемое значение 

Значение в формате Number, Boolean, Date, List, Text, Time Period  

## Эквивалент в Excel 

ЕСЛИ / IF 

### Примеры

```
IF 'Выручка' > 'Расходы' THEN "Успешно" ELSE "Работаем"
```

```
IF 'Выручка' > 'Расходы' 
THEN 
    IF 'Выручка' > 'Выручка конкурентов' 
    THEN "Успешно" ELSE "Работаем" 
ELSE 
    IF 'Расходы' < 'Расходы конкурентов' 
    THEN "Успешно" ELSE "Работаем"
```

```
IF 'Нужен комментарий?' 
THEN 
    (IF NOT BOOLEAN('Имя') 
    THEN "Необходимо имя." ELSE "") 
    & 
    (IF NOT BOOLEAN('Номер документа') 
    THEN "Необходим номер документа." ELSE "") 
ELSE ""
```
