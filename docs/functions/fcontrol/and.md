# AND

Проверяет значения аргументов и возвращает значение TRUE, если оба аргумента имеют значение TRUE. В противном случае возвращает значение FALSE. 

## Синтаксис 

*x* **AND** *y* 

## Аргументы 

- x: проверяемое логическое выражение
- y: проверяемое логическое выражение 

## Возвращаемое значение 

TRUE или FALSE (Логический формат) 

## Эквивалент в Excel 

И / AND 

## Пример 

a > 1000 AND b > 1000
