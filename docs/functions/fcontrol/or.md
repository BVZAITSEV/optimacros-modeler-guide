# OR 
Проверяет, является ли один из аргументов TRUE, и если да, то возвращает значение TRUE. Функция возвращает значение FALSE, если оба аргумента имеют значение FALSE. 

## Синтаксис 

*x* **OR** *y* 

## Аргументы 

- x: проверяемое логическое выражение
- y: проверяемое логическое выражение 

## Возвращаемое значение 

TRUE или FALSE (Логический формат) 

## Эквивалент в Excel 

ИЛИ / OR 

### Примеры

```
a > 1000 OR b > 1000 
```
!!! tip "Важно"
    AND имеет приоритет над OR, для переопределения правил приоритета используйте скобки. 

Определим логическое выражение для величин A=1, B=0, C=0. 

Куб К1 рассчитывается как: IF 'A' = 1 OR 'B' = 1 AND 'C' = 1 THEN 1 ELSE 2. Согласно приоритетности AND над OR, это равносильно выражению: IF 'A' = 1 OR ('B' = 1 AND 'C' = 1) THEN 1 ELSE 2. Результатом будет 1. 

Чтобы переопределить правила приоритета используем скобки для расчета куба К2: 

```
IF ('A' = 1 OR 'B' = 1) AND 'C' = 1 THEN 1 ELSE 2
```

В данном случае результатом будет 2.
