# Обработка битых формул

В случае обновления программного обеспечения система может быть настроена таким образом, чтобы игнорировать <term:Битая формула|битые формулы> - формулы, ставшие некорректными. При этом в целом работа модели не нарушается, даже если новая версия системы включает изменения в синтаксисе некоторых формул, изменения в работе с измерениями, или дополнительные проверки, встроенные в логику формул для улучшения кодирования бизнес-логики.

Моделер может принимать решения и анализировать ситуацию в каждом конкретном случае, исправляя некорректные решения в соответствии с обновлёнными требованиями, в том числе с помощью дополнительных полей `Error Comment`, `Stable View Formula` и `User View Formula`.

После обновления программного обеспечения Оптимакрос необходимо выполнить следующие действия:

 - Открыть таблицу кубов **Данные > Кубы**.
 - Проверить столбец **Формула**.
 - Для кубов, в которых поле Формула окрашено в красный цвет, провести анализ и внести необходимые изменения. 

![Ошибки в формулах после обновления ПО](formula-broken-001.png)

В поле **Формула** красным цветом выделены ячейки, содержащие некорректно рассчитанные значения. Эти ячейки находятся в режиме отключения автоматических пересчётов `AutoCalculation`.

!!! note "Важно"
    Отключение авто пересчёта позволяет вносить изменения в формулу, не затрагивая другие данные модели.

Информация из поля **Error Comment** поможет вам определить, какие изменения нужно внести. Чтобы увидеть описание ошибок в формуле, наведите курсор на ячейку с красным выделением в поле **Error Comment**.
 
![Всплывающее окно с описанием ошибок в формуле](formula-broken-002.png)

В поле **Формула** отображается **пользовательское представление**, если формула синтаксически корректна, но некорректна в работе с конкретным кубом (то есть функции в формуле используются правильно, но ссылки и данные некорректны).

Если формула синтаксически некорректна (то есть изменился синтаксис функций, используемых в формуле, и система не может правильно сформировать пользовательское представление), то в поле **Формула** отображается **стабильное представление**.

Дополнительные поля расширяют возможности отладки с помощью различных представлений формулы:

 - Stable View Formula — **стабильное представление** формулы (так формула представлена в базе данных системы)
 - User View Formula — **пользовательское представление** (так формула отображается для пользователя)

После успешной корректировки формулы куба красная заливка полей исчезает и поля `Error Comment`, `Stable View Formula`, `User View Formula` становятся пустыми.

## Пример  

Добавим два новых куба: `куб_1 `и `куб_2`. Свяжем эти кубы простым способом: пусть `куб_2` вычисляется по формуле, которая ссылается на `куб_1`. 

![Добавим два новых куба: `куб_1 `и `куб_2`](formula-broken-example-source-001.png)

Отключим автопересчет (поле `AutoCalculation`) у куба `куб_2`. 

![Отключим автопересчет (поле `AutoCalculation`) у куба `куб_2`](formula-broken-example-source-002.png)


Обратите внимание на содержимое полей **User View Formula**, **Stable View Formula** и **Формула** для `куб_2`. Поля **User View Formula** и **Формула** имеют пользовательское представление, которое аналогично представлению в редакторе формул:


![Поля User View Formula и Формула имеют пользовательское представление, которое аналогично представлению в редакторе формул](formula-broken-example-source-003.png)


После чего удалим `куб_1`: 

![Удалим `куб_1`](formula-broken-example-source-004.png)

Система позволяет выполнить это действие, поскольку автоматический пересчёт куба `куб_2` отключён. Это означает, что `куб_1` не связан с другими данными модели, и поэтому его удаление не вызовет проблем.

![Теперь поле Формула имеет представление, аналогичное полю Stable View Formula](formula-broken-example-result-001.png)


Теперь поле **Формула** имеет представление, аналогичное полю **Stable View Formula**. Система не может отобразить пользовательское представление, так как у нас нет куба, из которого можно было бы получить соответствующую информацию.

Кроме того, поле **User View Formula** теперь выделено красным цветом, а в окне, которое появляется при наведении курсора мыши на поле, отображается сообщение об ошибке.
