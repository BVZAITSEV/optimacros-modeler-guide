# MAXIF
Возвращает максимальное значение из множества ячеек кубов одного формата, указанных в аргументах и отфильтрованных по кубу логического формата. 

Функция является расширением функции [MAX](max.md). 

Принцип работы аналогичен [SUMIF](sumif.md). Для каждой ячейки кубов-аргументов находится соответствующая ей ячейка куба-условия по правилу формулы ссылки. Если соответствующая ячейка куба-условия содержит `TRUE`, то эта ячейка куба-аргумента участвует в поиске минимума, иначе она игнорируется.

## Синтаксис

MAXIF(X1,…,Xn, B) 

MAXIF(Выборка кубов, B) 

## Аргументы
- X1,…,Xn: кубы одного формата Дата или Число
- Только одна выборка кубов одного формата Дата или Число
- B: куб в логическом формате 

## Возвращаемое значение 

- Соответствует формату кубов `X1, …, Xn`, или кубов из выборки кубов
- Формат даты (Date\Дата)
- Числовой формат (Number\Число) 

## Эквивалент в Excel

МАКСЕСЛИ/MAXIFS  

## Пример

Условие возможности закупки товаров можно представить мультикубом с кубом в логическом формате, колонками которого являются месяцы. В ячейках, когда закупка товара возможна, стоит значение `TRUE`.  

Чтобы определить максимальную цену товаров в магазинах только в заданные месяцы, необходимо включить в список аргументов функции `MAXIF` все интересующие нас кубы: 

MAXIF('Цена в Шестерочке', 'Цена в Аржане', 'Цена в Кристале', 'Условие по времени'.'Разрешенные месяцы') 

![Пример функции MAXIF](f-maxif-result.md.png)

Поскольку февраль не включен в куб-условие, при поиске максимума, функция `MAXIF` игнорирует значения по этому измерению и возвращает `NaN`.
