# DATEPART

Функция `DATEPART` позволяет прибавлять к указанной дате или вычитать из указанной даты определенный период времени, такой как дни, недели, месяцы и годы.

## Синтаксис

DATEPART(X, Y)

## Аргументы

- X - дата в формате `DATE`.
    - Может быть любое выражение, возвращающее формат `DATE`.

- Y - часть даты, которую мы хотим получить, в формате `TEXT`.
    - Может быть только одним из ключевых слов: `DAY`, `MONTH`, `YEAR`. 

## Возвращаемое значение 

Возвращается, в зависимости от параметра Y, порядковый номер дня, месяца или года.

## Эквивалент в Excel

DatePart ( interval, date [, firstdayofweek] [, firstweekofyear] )
