# BOTIMEITEM
Принимает элемент измерения времени X и возвращает первый день периода времени, соответствующего Х, в формате Date. 

Если параметр не указан, используется выражение [ITEM(X)](item.md), возвращает первый день периода, ссылаясь на измерение времени исходного мультикуба. 

## Синтаксис

BOTIMEITEM()  

BOTIMEITEM(Х) 

## Аргументы
- X: выражение, возвращающее элемент измерения времени (time item) 

{% include 'bo-eo-timeitem-arguments.txt' %} 


## Возвращаемое значение 

формат Date 

Если аргументом функции является элемент измерения дней, то значение, возвращаемое функциями, совпадает со значением, возвращаемым функцией [DATE](date.md).

## Эквивалент в Excel

 нет
