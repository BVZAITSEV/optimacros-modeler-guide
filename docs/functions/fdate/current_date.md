# CURRENT_DATE
Возвращает текущую дату по UTC. 

Опциональный параметр X определяет смещение относительно времени UTC. 

## Синтаксис

CURRENT_DATE()  

CURRENT_DATE(X) 

## Аргументы 

- X: числовая константа - смещение относительно времени UTC  

## Возвращаемое значение 

формат Date 

## Эквивалент в Excel

 ТДАТА/NOW
