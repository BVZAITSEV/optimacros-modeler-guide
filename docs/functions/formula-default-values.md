# Значение по умолчанию

Значение по умолчанию (`NULL`-значение) – значение, зависящее от формата куба, которое может в некоторых случаях возвращаться функциями.


| Формат куба | Значение по умолчанию |
| --- | --- |
| числовой с NaN | `NaN` |
| числовой без NaN | `0` |
| дата | пустая дата |
| логический (Boolean) | `FALSE` |
| измерения (Справочник, Версия, Выборка кубов, Время) | `NULL`|
