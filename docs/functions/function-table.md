# Таблица функций 

## Управляющие структуры
| Функция | Краткое описание |
| --- | --- |
|[IF THEN ELSE](if-then-else.md) | IF x THEN y ELSE z <br/> Проверяет аргумент истины и возвращает одно из двух значений на основе результата. |
|[AND](and.md) | (x) AND (y)  <br/> Проверяет значения аргументов и возвращает значение TRUE, если оба аргумента имеют значение TRUE. В противном случае возвращает значение FALSE. |
|[OR](or.md)| (x) OR (y)  <br/> Проверяет, является ли один из аргументов TRUE, и если да, то возвращает значение TRUE. Функция возвращает значение FALSE, если оба аргумента имеют значение FALSE. |
|[NOT](not.md)| NOT(x)  <br/> Изменяет значение FALSE на TRUE, а TRUE на FALSE. |

## Логические функции для работы с элементами измерений 
| Функция | Краткое описание |
| --- | --- |
|[IN_DIMENSION](in_dimension.md)| IN_DIMENSION(X)   IN_DIMENSION(Х, Y)  <br/> Проверяет входит ли элемент Y в состав измерения Х. Y должно быть выражением, возвращающим элемент измерения совместимого с X. Возвращает TRUE если результат вычисления Y содержится в X. Иначе возвращает FALSE. |
|[IN_DIMENSION_EXACT](in_dimension_exact.md)| IN_DIMENSION_EXACT(X)  IN_DIMENSION_EXACT(Х, Y)   Аналогично функции IN_DIMENSION проверяет, входит ли элемент Y в состав измерения Х, но позволяет искать значения только в указанном справочнике, без поиска по всей иерархии.  Вернет значение TRUE только для ячеек, которые входят в измерение, указанное в качестве аргумента функции. |[IS_PARENT](is_parent.md)| IS_PARENT()  <br/> Возвращает TRUE, если ячейка является родительской хотя бы для одного из элементов измерений, иначе возвращает FALSE. |

|[IS_DESCENDANT](is_descendant.md)| IS_DESCENDANT (X, [Y1, Y2, …])  <br/> Возвращает TRUE, если элемент измерения является потомком хотя бы для одного из элементов, указанных в [] скобках. |

|[IS_IN, IN](is_in.md)| IS_IN(X, [Y1, Y2, …])  X IN [Y1, Y2, …]  <br/> Возвращает TRUE для значения в случае, если оно присутствует в множестве значений элементов, указанных в [] скобках. |
