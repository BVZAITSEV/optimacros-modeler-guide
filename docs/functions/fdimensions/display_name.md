# DISPLAY_NAME

Функция DISPLAY_NAME предназначена для получения отображаемого имени элемента измерения (пользовательский справочник, версии и время).

## Синтаксис

DISPLAY_NAME(X) 

## Аргументы
- X: 
    - ITEM('выражение, возвращающее формат справочника, периода времени и версий')
    - куб, свойство в формате другого справочника

## Возвращаемое значение 

Текст 

## Эквивалент в Excel

нет

## Функция DISPLAY_NAME и иерархические справочники

Для каждого уровня справочника необходимо настроить отдельное имя, которое будет отображаться (DISPLAY NAME, DN). Например, если есть иерархия справочников `Регионы — Города`, то для городов DN будет настраиваться в справочнике `Города`, а для регионов — в справочнике `Регионы`. Если мы используем функцию `DISPLAY_NAME` и указываем `Formula` для итогов, то функция должна возвращать корректное значение для каждого уровня справочника.

![Справочник Регионы](f-display_name-hierarchy-001.png)

![Пример DISPLAY_NAME и измерение Города с родителем Регионы ](f-display_name-hierarchy-002.png)

**DN\_Города:** DISPLAY_NAME(ITEM('Города'))  
**DN\_Регионы:** DISPLAY_NAME(PARENT(ITEM('Города')))  
**DN_Formula:** такая же формула как и в DN\_Города, но в итогах выбрана Formula

## Display Name и Item Name

Если свойство справочника используется в качестве `Display Name` и не все ячейки этого свойства заполнены, то в заголовке измерения будет отображаться `Item Name`.
