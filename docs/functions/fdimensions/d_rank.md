# D_RANK
Возвращает ранг элемента измерения в числовом формате Число/Number. **Ранг** – число которое ставится в соответствие каждому элементу измерения по некоторым правилам (на текущий момент – эвристикам). 

## Синтаксис

D_RANK(X) 

## Аргументы
- X: любое выражение возвращающее элемент измерения.  

Получить ранг элемента можно используя следующее: 

- функцию [ITEM](item.md): ```D_RANK(ITEM(‘Измерение_1’))```
- куб в формате измерения:  ```D_RANK(‘Куб_1’)```
- ссылки на элемент: ```D_RANK(‘Измерение_1’.’Элемент_1’)``` 

## Возвращаемое значение 

Числовой формат (Число/Number) 

Возвращаемое значение — это ранг элемента измерения, начиная с 1.  

## Эквивалент в Excel

нет  

## Пример

Рассмотрим мультикуб, в столбцах которого справочник `Нум10`, а в строках куб с элементами справочника `Продукты питания`.
