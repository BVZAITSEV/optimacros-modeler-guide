# PARENT
Принимает элемент справочника в качестве параметра и возвращает родительский элемент. 

Данная функция используется в иерархичных справочниках, где требуется вернуть родительский элемент, принадлежащий справочнику нижнего уровня. 

## Синтаксис

PARENT(X) 

## Аргументы 

- X: формат Справочника, Периода времени, который может быть рассчитан как `X= ITEM(X)` 

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом `Х`.

## Эквивалент в Excel

нет 

## Пример

В данном примере простой двумерный мультикуб, кубы которого представлены в столбцах, и справочник Рынки сбыта в строках. Куб Территория использует функцию ITEM для возврата элемента справочника Рынки сбыта для строки, и затем функция PARENT возвращает родительский элемент этого элемента справочника. 

```
PARENT(ITEM('Рынки сбыта')) 
```
