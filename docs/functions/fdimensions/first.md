# FIRST
Возвращает первый элемент измерения, используемого в мультикубе. 

## Синтаксис

FIRST(ITEM(X)) 

FIRST(Y)  

## Аргументы
- X: измерение, используемое в мультикубе 
- Y: куб в формате измерения, используемого в мультикубе 

## Возвращаемое значение 

соответствует формату данных, используемому аргументом 

## Эквивалент в Excel

нет
