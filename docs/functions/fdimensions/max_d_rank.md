# MAX_D_RANK
Возвращает максимальный ранг элементов измерения в числовом формате Число/Number. **Ранг** – число которое ставится в соответствии каждому элементу измерения по некоторым правилам (на текущий момент – эвристикам). 

## Синтаксис

MAX_D_RANK(X) 

## Аргументы 

- X: выражение, возвращающее формат справочника (или его выборку) 

## Возвращаемое значение 

Числовой формат (Число/Number) 

Возвращаемое значение — это максимальный ранг всех элементов измерения. 

## Эквивалент в Excel

нет 

## Пример

Рассмотрим мультикуб, в столбцах которого справочник `Нум10`, а в строках куб с элементами справочника `Продукты питания`. 

 

Определим максимальный ранг элементов справочника данного справочника по формуле: 

```
MAX_D_RANK('Продукты питания') 
```

Используя функции `MAX_D_RANK` и [D_RANK](d_rank.md) по формуле:

```
MAX_D_RANK('Продукты питания') = D_RANK('Продукт')
```
можно определить является ли элемент измерения **листовым**.
