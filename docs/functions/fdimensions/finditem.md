# FINDITEM
Принимает измерение *X* в качестве первого параметра и текст *Y* в качестве второго параметра. Возвращает элемент измерения с указанным кодом или названием. 

Дополнительный параметр *Z1* уточняет, где будет происходить поиск: «0» – строго по указанному измерению, «1» – по всей иерархии указанного измерения. Если параметр не указан, по умолчанию поиск элемента происходит строго по указанному измерению *X*. 

Дополнительный параметр *Z2* уточняет чувствительность к регистру: «0» – учитывать регистр, «1» – не учитывать регистр. Если параметр не указан, по умолчанию поиск элемента происходит с учетом регистра. 

!!! note "Важно" 
    Поиск элемента измерения происходит сначала по коду (`Code`), затем по имени элемента (`Item Name)`. Учитывайте это при присвоении элементам наименований, совпадающих с кодами других элементов измерения. 

К аргументу *Y* функции `FINDITEM` применяется функция [CLEAN](clean.md). Чтобы выполнять поиск точного вхождения `Y`, используйте функцию `FINDITEM_EXACT`. 

## Синтаксис

FINDITEM(X, Y) 

FINDITEM(X, Y, Z1) 

FINDITEM(X, Y, , Z2) 

FINDITEM(X, Y, Z1, Z2)  

FINDITEM_EXACT(X, Y) 

FINDITEM_EXACT(X, Y, Z1) 

FINDITEM_EXACT(X, Y, , Z2) 

FINDITEM_EXACT(X, Y, Z1, Z2) 

## Аргументы 

- X: любое измерение или его выборка
- Y: формат Text: текстовое выражение, возвращающее название искомого элемента;
- Z1: дополнительный параметр, уточняющий место поиска элемента: «0» или "list" – строго по указанному измерению, «1» или "hierarchy" – по всей иерархии указанного измерения
- Z2: дополнительный параметр, определяющий чувствительность к регистру: «0» или «case_sensitive» – учитывать регистр, «1» или «case_insensitive» – не учитывать регистр

## Возвращаемое значение 

Элемент измерения `X`.

## Эквивалент в Excel

ВПР/LOOKUP
