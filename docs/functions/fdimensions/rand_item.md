# RAND_ITEM
Возвращает в куб случайный элемент измерения `X`. 

При обновлении функции `RAND_ITEM` возвращается новый случайный элемент. 

Если аргумент не указан, функция возвращает элемент измерения, используемый в качестве формата куба.  

Если в качестве аргумента указан справочник, имеющий вложенную иерархию, функция возвращает только элементы нижнего уровня данного справочника, не имеющие дочерних элементов. 

## Синтаксис

RAND_ITEM() 

RAND_ITEM(X) 

## Аргументы 

- X: любое измерение или его выборка 

## Возвращаемое значение 

соответствует формату данных, используемых аргументом `Х`
