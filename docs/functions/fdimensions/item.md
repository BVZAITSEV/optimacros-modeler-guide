# ITEM 
Возвращает элемент измерения X.  

## Синтаксис

ITEM(X) 

## Аргументы 

- X: любое измерение или его выборка 

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом `Х`. 

## Эквивалент в Excel

Нет
