# INTERPOLATE
Строит кусочно-линейную интерполяцию функции, заданной в табличном виде через аргументы X и Y, и возвращает ее значение в точке x.  

!!! warning ""
    В некоторых случаях для корректной работы функции необходимо перезапустить модель.
 
## Синтаксис

INTERPOLATE(x, X, Y) 

## Аргументы 

- x: формат Число/Number: числовая константа, куб или выражение
- X: формат Число/Number: куб
- Y: формат Число/Number: куб  

## Возвращаемое значение 

формат Число/Number 

## Эквивалент в Excel

ПРЕДСКАЗ/FORECAST 

## Пример

```
INTERPOLATE(X, Sample.X, Sample.'f(X)') 
```
