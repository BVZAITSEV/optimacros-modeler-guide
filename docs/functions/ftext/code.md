# CODE
Принимает элемент справочника в качестве параметра и возвращает код элемента в текстовом формате. 

## Синтаксис

CODE(X) 

## Аргументы
- X: выражение, возвращающее формат справочника (или его выборку) 

## Возвращаемое значение 

текстовый формат 

## Эквивалент в Excel

ПРОСМОТР/LOOKUP
