# SUBSTITUTE
Находит в тексте X текстовые символы Y и заменяет на другие текстовые символы Z. 

## Синтаксис

SUBSTITUTE(X, Y, Z) 

## Аргументы
- X: формат Text, текстовая или символьная константа
- Y: формат Text, текстовая или символьная константа
- Z: формат Text, текстовая или символьная константа

!!! note "Важно"
    - Текстовые или символьные константы должны быть заключены в двойные кавычки ""
    - Текстовые константы должны быть на латинице
    - Чтобы заменить двойные кавычки в строке, недостаточно экранировать кавычку обратным слэшем (\). Для этого необходимо использовать код ASCII-символа в шестнадцатеричной системе счисления (HEX). Для двойной кавычки это значение будет равно “\x22”. То есть чтобы заменить двойные кавычки на пробел необходимо использовать следующую формулу: `SUBSTITUTE(‘куб с текстом’, “\x22”, “ “)`.

## Возвращаемое значение 

формат Text 

## Эквивалент в Excel

ПОДСТАВИТЬ/ SUBSTITUTE

Для элемента измерения `январь` и куба `Шишки` с текстом: *Январский сбор: 2, 5, 12* значения кубов определяются как:

- Куб `Вася`: 
    ```
    NUMBER(SUBSTITUTE('Шишки', "\D*(\d+), *(\d+), *(\d+).*", "$2"))
    ```
    – это **5**
- Куб `Петя`: 
    ```
    NUMBER(SUBSTITUTE('Шишки', "\D*(\d+), *(\d+), *(\d+).*", "$1"))
    ```
    – это **2**
- Куб `Осталось`: 
    ```
    NUMBER(SUBSTITUTE('Шишки', "\D*(\d+), *(\d+), *(\d+).*", "$3"))
    ```
    – это **12**
- Куб `Развернутый результат`: 
    ```
    SUBSTITUTE('Шишки', "\D*(\d+), *(\d+), *(\d+).*", "Вася собрал $2 шишек, а Петя $1. На полу осталось $3")
    ```
    – это **Вася собрал 5 шишек, а Петя 2. На полу осталось 12**

## Синтаксис регулярных выражений

Следующие элементы регулярных выражений могут использоваться в аргументах функции SUBSTITUTE:

### Символы

| Символ | Описание | Пример |
| :---: | --- | ---|
| \| | **Альтернация** «ИЛИ» обозначается символом вертикальной черты '\|' и позволяет выбирать между вариантами.<br/>Альтернация работает не посимвольно, а на уровне фраз и подвыражений.<br/>Для указания границ альтернации используют скобки (... | `A\|B\|C` - поиск одного из выражений: A, B или C. <br/>`before(XXX\|YYY)after` будет искать beforeXXXafter или beforeYYYafter.|
| ^ | **Начало строки** <br/>Знак каретки перед выражением позволяет искать только значения, начинающиеся с данного выражения.| `^AA` найдет только AAD из списка AAD, BAA, CAA, ABC |
| $ | **Конец строки** <br/>Знак доллара перед выражением позволяет искать только значения, заканчивающиеся данным выражением.| `AA$` найдет BAA и CAA из списка AAD, BAA, CAA, ABC |
| . | **Точка** <br/> Шаблон, обозначающий количество символов (в соответствии с указанным количеством точек) | `^м....а$` ищет выражение, которое начинается с 'м', заканчивается на 'а' и содержит 6 символов. |
| \[ab\] | **Наборы** <br/>Поиск любого из символов или символьных классов, заключенного в квадратные скобки. | `В[уа]ля` будет искать Вуля или Валя.|
| \[a-z\] | **Диапазоны** <br/>Поиск любого из символов или символьных классов, заключенного в квадратные скобки в диапазоне «от» -«до». | `[a-z]` – произвольный символ от a до z <br/> `[0-5]` – цифра от 0 до 5 |
| \[^ab\] | **Диапазоны «кроме»**. Исключающие диапазоны. <br/>Квадратные скобки, начинающиеся со знака каретки: `[^]` находят любой символ, кроме указанных в квадратных скобках.<br/>В квадратных скобках большинство специальных символов можно использовать без экранирования.| `[^аеуо]` – любой символ, кроме 'a', 'e', 'y', 'o'. <br/>`[^0-9]` – любой символ, кроме цифры<br/>`[-().^+]` будет искать любой из символов в квадратных скобках |
 \ | **Экранирование** для поиска специальных символов.<br/>Для поиска значений, содержащих специальные символы, в строке поиска перед символом должен быть введен обратный слэш `\` <br/>К специальным символам относятся: `[ \ ^ $ . | ? * + ( )` | `\(` - ищет все значения, содержащие символ '(' <br/> `\(953\)` - Будет искать номера телефонов, содержащие код '(953)'|


### Классы для поиска символов

| Класс | Описание |
| --- | --- |
| \d - цифры | Поиск всех значений, содержащих цифры|
| \D - не-цифры | Поиск всех значений, содержащих другие символы, кроме \d, например буквы |
| \s - пробельные символы | Поиск всех значений, содержащих пробельные символы: пробел, табуляция, перевод строки, возврат каретки | 
| \S – всё, кроме \s | Поиск всех значений, содержащих другие символы, кроме \s |
| \w - латиница, цифры | Поиск всех значений, содержащих латиницу, цифры|
| \W – всё, кроме \w | Поиск всех значений, содержащих другие символы, кроме \w | 
| \b – граница слова | Поиск значений, обозначающих не символ, а границу между символами |

### Квантификаторы

| Элемент | Описание | Пример |
| :---: | --- | --- |
| {} | **Количество {n}** - Количество повторений символа можно указать с помощью числа в фигурных скобках: {n} | `\d{5}` - ровно 5 цифр, находит пятизначное число<br/>`\d{3,5}` - находит числа размером от трёх до пяти знаков <br/> `\d{3,}` - найдет числа, длиной от трех цифр. |
| + | «один или более», то же что {1,} | `\d+` - находит числа – последовательности из 1 или более цифр |
| ? | «ноль или один», то же что и {0,1}, делает символ необязательным | `ou?r` - найдёт 'o', после которого, возможно, следует 'u', а затем 'r |
| * | «ноль или более», то же что {0,} | Символ, после которого стоит '*' может повторяться много раз или отсутствовать. |

Часть выражения может быть заключена в круглые скобки (). Квантификатор, проставленный после выражения в скобках () применится ко всей скобке, а не к отдельному символу.
