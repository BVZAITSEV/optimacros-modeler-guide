# LENGTH
Возвращает количество символов в текстовом кубе. 

## Синтаксис

LENGTH(X) 

## Аргументы
- X: текстовый формат 

## Возвращаемое значение 

числовой формат 

## Эквивалент в Excel

ДЛСТР/LEN
