# CLEAN
Заменяет в тексте на один символ пробела следующие символы: 

- табуляция (горизонтальная/вертикальная)
- перенос строки (включая возврат каретки)
- несколько подряд идущих пробелов
- пробелы в начале и конце строки 

## Синтаксис

CLEAN(X) 

## Аргументы
- X: формат Text 

## Возвращаемое значение 

формат Text 

## Эквивалент в Excel

ПЕЧСИМВ/CLEAN
