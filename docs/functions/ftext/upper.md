# UPPER
Принимает в качестве параметра любое выражение, возвращающее текст, и возвращает текст, преобразованный в верхний регистр. 

## Синтаксис

UPPER(X) 

## Аргументы
- X: выражение, возвращающее текст 

## Возвращаемое значение 

текстовый формат 

## Эквивалент в Excel

ПРОПИСН / UPPER
