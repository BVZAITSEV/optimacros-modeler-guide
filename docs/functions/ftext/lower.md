# LOWER
Принимает в качестве параметра любое выражение, возвращающее текст, и возвращает текст, преобразованный в нижний регистр. 

## Синтаксис

LOWER(X) 

## Аргументы
- X: выражение, возвращающее текст 

## Возвращаемое значение 

текстовый формат 

## Эквивалент в Excel

СТРОЧН / LOWER
