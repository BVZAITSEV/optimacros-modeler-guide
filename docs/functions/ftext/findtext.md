# FINDTEXT
Ищет позицию подстроки X в строке S. 

Дополнительный параметр N позволяет указать начальную позицию для поиска. Если параметр не указан, по умолчанию поиск элемента происходит с начала строки. 

Первый символ имеет индекс 1. 

## Синтаксис

FINDTEXT(X, S, N) 

## Аргументы
- X: куб в текстовом формате или текстовая константа
- S: куб в текстовом формате или текстовая константа
- N: целое число (опциональный параметр)

!!! note "Важно"
    Текстовые или символьные константы должны быть заключены в двойные кавычки "" 

## Возвращаемое значение 

числовой формат 

## Эквивалент в Excel

НАЙТИ/FIND
