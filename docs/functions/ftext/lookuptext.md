# LOOKUPTEXT
Извлекает заданное число символов из текстового выражения, начиная с указанной позиции. 

## Синтаксис

LOOKUPTEXT(X, Y, N) 

## Аргументы
- X: произвольное текстовое выражение, из которого будет извлекаться подстрока
- Y: произвольное числовое выражение, результат которого (округленный к ближайшему целому) равен позиции первого символа извлекаемой подстроки в исходной строке
- N: произвольное числовое выражение, результат которого (округленный к ближайшему целому) равен количеству символов извлекаемой подстроки

!!! note "Важно"
    Нумерация позиций символов исходной строки начинается с нуля. 

## Возвращаемое значение 

текстовый формат 

## Эквивалент в Excel

ПСТР/MID
