# NAME
Принимает элемент справочника в качестве параметра и возвращает название элемента в текстовом формате. 

## Синтаксис

NAME(X) 

## Аргументы
- X: выражение, возвращающее формат справочника, периода времени, версий, их выборок или выборки кубов. 

## Возвращаемое значение 

текстовый формат

T/T
