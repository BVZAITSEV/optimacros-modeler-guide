# MATCH
Сравнивает два текстовых значения и возвращает значение TRUE, если они совпадают, в противном случае – FALSE. 

## Синтаксис

MATCH(X, Y) 

## Аргументы
- X: формат Text, текстовая или символьная константа
- Y: формат Text, текстовая или символьная константа 

!!! note "Важно"
    - Текстовые или символьные константы должны быть заключены в двойные кавычки ""

## Возвращаемое значение 

формат Boolean 

## Эквивалент в Excel

СОВПАД/EXACT
