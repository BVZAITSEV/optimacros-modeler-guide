# TIMESUM
Возвращает в куб суммарное значение по кубу Х в промежутке времени от Y1 до Y2. 

## Синтаксис

TIMESUM(X, Y1, Y2) 

## Аргументы

- X: куб в формате Number
- Y: могут использоваться: 
    - абсолютные значения времени `Time.'Period'`, например, `Days.'1 Jan 18'`
    - относительные, например, `0` – текущий период, `-1` – предыдущий, `1` - следующий после текущего
    - выражения, возвращающие элемент измерения времени (time item), например, `DAY(EOMONTH()`). 


Y1 не может быть меньше Y2 для относительных значений границ, при абсолютных значениях границ Y2 должен следовать в справочнике после элемента Y1.

В аргументах Y1 и Y2 могут быть вложенные функции, если они возвращают элемент справочника времени, который присутствует как в мультикубе-источнике, так и в мультикубе-приемнике.

В аргументах Y1 и Y2  могут быть ссылки на кубы в формате справочников времени, если их элементы присутствуют как в мультикубе-источнике, так и в мультикубе-приемнике.

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х 

- При относительных границах диапазона времени в ячейки куба вернутся разные значения в зависимости от исходных данных.
- При абсолютных границах диапазона во все ячейки куба вернется одинаковое значение.

Функция выдаст ошибку, если в первом аргументе указать куб, в котором она применяется.

Формула вернет 0 в те ячейки куба, по которым не может произвести расчеты (например, нарушен порядок элементов времени или в справочнике отсутствует предыдущий элемент).

Суммирование происходит, **включая** указанные границы временного диапазона.

## Эквивалент в Excel

нет 

## Пример

Исходный мультикуб `Доходы`, в строках которого находится справочник `Компании`, в колонках – измерение времени `Months`, в фильтрах – куб `Данные`:

![Исходный мультикуб `Доходы`](f-timesum-source-001.png)

В результирующем мультикубе, в колонках которого находится измерение времени `Months`, в фильтрах – справочник `Компании` и в строках – кубы, рассчитаем сумму по кубу `Date` мультикуба `Доходы`.

| Описание | Формула |
| --- | --- |
| за текущий период | TIMESUM(Доходы.Данные, 0, 0) |
| за текущий период | TIMESUM(Доходы.Данные, 0, 0) |
| за предыдущий период | TIMESUM(Доходы.Данные, -1, -1) |
| последние три месяца | TIMESUM(Доходы.Данные, -2, 0) |
| с января 2018 по текущий период | TIMESUM(Доходы.Данные, Months.'Jan 18', 0) |
| за 2018 год | TIMESUM(Доходы.Данные, Months.'Jan 18', Months.'Dec 18') |
| за 2019 год | TIMESUM(Доходы.Данные, Months.'Jan 19', Months.'Dec 19') |
| за 12 предыдущих месяцев и текущий включительно | TIMESUM(Доходы.Данные, -12, 0) |
| с июня 2018 по август 2019 | TIMESUM(Доходы.Данные, Months.'Jun 18', Months.'Aug 19') |
