# RAND_NUMBER
Возвращает случайное целое число, расположенное в интервале между двумя заданными числами. 

При пересчете функции RAND_NUMBER возвращается новое случайное число. 

## Синтаксис

RAND_NUMBER() 

RAND_NUMBER(нижн_граница,верхн_граница) 

## Аргументы
- нижн_граница: Наименьшее целое число, которое возвращает функция RAND_NUMBER
- верхн_граница: Наибольшее целое число, которое возвращает функция RAND_NUMBER 

## Возвращаемое значение 

Целое число 

## Эквивалент в Excel

СЛЧИС/RAND 

СЛУЧМЕЖДУ/RANDBETWEEN 

## Пример

Мультикуб содержит два справочника `Компании` и `Продукты`, измерение времени `Months` и куб `Значение` с формулой, генерирующей случайные целые числа в интервале от -1000 до 5000: 

```
RAND_NUMBER(-1000, 5000)
```
