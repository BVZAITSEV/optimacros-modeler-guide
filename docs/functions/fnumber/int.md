# INT
Возвращает в куб целую часть числа, округляя до ближайшего меньшего целого числа. 

## Синтаксис

INT(X) 

## Аргументы
- X: числовой формат (Число\Number)  

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х 

## Эквивалент в Excel

ЦЕЛОЕ/INT
