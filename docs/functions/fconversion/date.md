# DATE
Преобразует выражение в формате периода времени, числовом или текстовом формате в дату. 

## Особенности работы с различными форматами

### Формат измерения времени

- Дни: преобразует дни в дату. Функция обратная функции [DAY](day.md). 
- Недели, Месяцы, Периоды, Кварталы, 9 месяцев, Года: возвращает дату первого дня соответствующего периода. 

### Числовые выражения

Преобразует значения в дату аналогично Excel, где числовому значению «2» соответствует дата 01.01.1900г[^1]. 

[^1]:
    Excel ошибочно посчитал 1900г. високосным и включил в расчеты несуществующую дату 29.02.1900г.

    Для поддержания совместимости с Excel в Optimacros порядок для 01.01.1900 начинается с «2», 02.01.1900 – «3» и т.д., и отличается на единицу от порядка в Excel, вплоть до 01.03.1900г, далее порядковые номера дат являются сопоставимыми. 

Функция является обратной функции [NUMBER](number.md) при работе с датами. 

### Текстовые выражения

Преобразует текстовое значение в дату. Функция является обратной функции [TEXT](text.md) при работе с датами. 

Функция распознает текстовые выражения в формате `дд*мм*гг`, `дд*мм*гггг`, где * - символьный разделитель дней, месяцев и годов. 

Для преобразования текстовых выражений могут быть использованы дополнительные параметры: 

- `FORMAT` – параметр, позволяющий определить пользовательский формат текста для распознаваемого значении даты
- `LOCALE` – параметр, позволяющий определить региональные настройки текста для распознаваемого значении даты. 

{%include 'format-specifiers.txt' %}

Символьный разделитель в строке формата может быть любым из следующего набора: дефис, косая черта, двоеточие, точка, пробел. При распознавании выражения различия между ними не делается, однако рекомендуется в строке формата указывать символ, соответствующий распознаваемым данным.

## Синтаксис

DATE(X) 
 

Расширенный синтаксис для текстовых выражений: 

DATE(X, LOCALE:"A") 

DATE(X, FORMAT:"B") 

DATE(X, LOCALE:"A", FORMAT:"B") 

## Аргументы 

- X: выражение, возвращающее период времени, число или текст
- A: название локали (региональных настроек), такое как `en_US` или `ru_RU` 
- B: выражение-спецификатор, задающее формат даты для распознавания, например `%d,%b %Y` для даты 08,AUG 2024 в локали en_US

## Возвращаемое значение 

формат даты 

## Эквивалент в Excel

нет
