# DEFAULT_VALUE
Функция возвращает дефолтное значение (по умолчанию) формата данных куба. 

## Синтаксис

DEFAULT_VALUE() 

## Аргументы
Функция не требует аргументов 

## Возвращаемое значение 

Соответствует формату данных куба 

## Эквивалент в Excel

Нет
