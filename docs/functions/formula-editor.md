# Редактор формул


Область редактора формул находится в табличном представлении мультикуба/справочника под панелью инструментов:


![Область редактора формул](formula-editor-001.png)

Чтобы ввести формулу, выберите нужный куб или свойство справочника и установите курсор в поле редактора формул. Если необходимо, можно раскрыть область редактора, нажав на стрелку вниз рядом с названием куба.

![Активация редактора формул](formula-editor-002.png)


Размер области редактора можно изменить, потянув за нижнюю границу:

![Размер области редактора можно изменить](formula-editor-003.png)



Чтобы упростить ввод имён кубов (или свойств в справочниках), можно скопировать их названия в формулу одним щелчком мыши. Для этого после начала ввода текста в поле редактора нажмите на имя куба или свойства в таблице, и оно появится в редакторе формул.

!!! tip ""
    Если формула начинается с названия куба, то для активации режима редактирования (чтобы скопировать название щелчком мыши) нажмите символ "=". Наличие "=" в начале формулы не влияет на ее выполнение.

![Ввод имени куба щелчком мыши](formula-editor-004.png)


Введите формулу и подтвердите ввод одним из следующих способов:

- При работе в открытой панели редактора формул нажмите ++enter++. В появившемся диалоге **Подтвердить изменения** нажмите **OK**:

    ![Диалог подтверждения изменений](formula-editor-confirm-dialog.png)

- Нажмите зеленую галочку на панели редактора формул:

    ![Подтверждение ввода](formula-editor-005-confirmation.png)



Чтобы отменить редактирование и не сохранять изменения, нажмите ++esc++ или красный крестик на панели редактора формул.


**Подсветка синтаксиса** в редакторе формул помогает визуально определить ошибку при неправильном написании формулы. Подсветка включается автоматически при редактировании формулы. Выключить или включить подсветку можно нажав на кнопку `Подсветка` на панели редактора формул:

![Включение подсветки в редакторе формул](formula-editor-006-highlight.png) 


## Советы по вводу названий элементов

При редактировании формулы для вставки названия куба из текущего мультикуба щелкните по заголовку нужного куба.

Если требуется название куба из другого мультикуба, то в редакторе формул перейдите к списку мультикубов через диалог [Содержимое модели](model-contents-dialog.md) или главное меню, затем щелкните по заголовку нужного куба, как показано ниже:

![Вставка названия куба из другого мультикуба](formula-editor-enter-cubes.gif)

Если в формуле требуется использовать элемент справочника, версии или измерения времени, то в редакторе формул вызовите главное меню для перехода к нужному измерению и выберите элемент, щёлкнув по его заголовку.

Выбранные элементы автоматически выделяются одинарными кавычками в окне редактора формул. При ручном вводе убедитесь, что название элемента, которое содержит пробелы или другие специальные символы, заключено в одинарные кавычки.

Для удобства чтения формулы, элементы и функции разделяйте пробелами. Для кубов в числовом формате сочетание «+ 0 +» в формульном выражении позволяет сделать перенос строки в редакторе формул и улучшить читаемость выражения.
