# IRR
Вычисляет внутреннюю ставку доходности для ряда потоков денежных средств. 

*Внутренняя ставка доходности (IRR, внутренняя норма доходности)* – процентная ставка инвестиционного проекта, при которой приведенная стоимость денежных потоков равняется нулю. При данной ставке инвестор вернет вложенные первоначально средства. Инвестиции состоят из платежей (суммы со знаком «–») и доходов (со знаком «+»), которые происходят в одинаковые по продолжительности временные промежутки. 

## Синтаксис

IRR(X) 

IRR(X, R) 

## Аргументы
- X: куб в числовом формате (Число\Number), имеющий измерение времени
- R: числовое значение, предположительно близкое к ставке доходности – необязательный аргумент, необходим, когда существует несколько решений. 

## Возвращаемое значение 

Числовой формат Number  

## Эквивалент в Excel

ВСД/IRR 

## Особенности IRR

- Если в целевом кубе есть измерение времени, то IRR учитывает периоды начиная от текущего и до последнего в измерении времени.
- Если в целевом кубе нет измерения времени, а в кубе X есть, то учитываются все периоды в измерении времени. 
- Если ни в одном из кубов нет измерения времени, то функция возвращает ошибку. 
- В случае невозможности найти решение функция возвращает 0. 
- Решение ищется с точностью до 5 знаков после запятой. 
- В связи с тем, что функция сложная, вычисляется итерационным способом и не всегда возможно визуально определить, насколько корректное значение ставки получается в результате ее выполнения, целесообразно вводить в модель контроль `NPV(IRR)=0`. 
- Использовать во временном ряду хотя бы одно отрицательное значения обязательно. 
- Если указать в качестве дополнительного аргумента 0, то в функции может возникнуть бесконечный цикл, который приведет к зависанию запроса. 
- В большинстве случаев оправданно использовать `IRR` c аргументом `Guess = 0.1`.
- В случае, если с дополнительным аргументом 0.1 решение не найдено (функция возвращает 0), `IRR` можно подобрать вручную следующим образом: `IRR` равен значению при котором `NPV(CF, IRR) ~ 0`

## Пример контроля NPV(IRR)

Аргумент `R` функции следует подбирать так, чтобы `NPV(IRR)` принимало значения близкие к нулю. 

Если напрямую задавать в кубе `NPV by IRR` формулу, то возникает рекурсия, которую можно обойти стандартным способом – через дополнительный мультикуб.
