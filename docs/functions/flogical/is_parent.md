# IS_PARENT
Данная функция используется для иерархичных измерений, где требуется определить родительский элемент, принадлежащий измерению нижнего уровня. 

Возвращает `TRUE`, если ячейка является родительской хотя бы для одного из элементов измерений, иначе возвращает `FALSE`.  

Функция применяется для метода расчета родительских элементов измерений `Formula`. 

Функция не требует аргументов. 

## Синтаксис

IS_PARENT() 

## Аргументы
не требует аргументов 

## Возвращаемое значение 

логический формат/ Boolean 

## Эквивалент в Excel

нет
