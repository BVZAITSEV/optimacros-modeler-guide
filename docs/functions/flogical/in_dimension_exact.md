# IN_DIMENSION_EXACT
Аналогично функции [IN_DIMENSION](in_dimension.md) проверяет, входит ли элемент `Y` в состав измерения `Х`.  

В мультикубах, построенных на справочниках без иерархии, функции [IN_DIMENSION](in_dimension.md) и `IN_DIMENSION_EXACT` вернут одинаковые значения. 

В отличие от [IN_DIMENSION](in_dimension.md) в мультикубах, построенных на справочниках с иерархией, функция `IN_DIMENSION_EXACT` вернет значение `TRUE` только для ячеек, которые входят в измерение, указанное в качестве аргумента функции. Для справочников, находящихся выше в иерархии, функция вернет значение `FALSE`.  

## Синтаксис

IN_DIMENSION_EXACT(X)  

IN_DIMENSION_EXACT(Х, Y) 

## Аргументы 

- X: измерение (или выборка) Справочника, Версий, Периода времени
- Y: выражение, возвращающее элемент измерения совместимого с X. Если не указано, то используется выражение ITEM(X). 

## Возвращаемое значение 

логический формат/ Boolean 

## Эквивалент в Excel

нет 

## Пример 

На примере мультикуба, построенного на выборке измерения `Days` и справочнике `Города` с родителем `Регионы`, сравним результаты вывода `IN_DIMENSION_EXACT` и [IN_DIMENSION](in_dimension.md). 

Для родительского справочника Регионы функция [IN_DIMENSION](in_dimension.md) возвращает результат `TRUE`, тогда как функция `IN_DIMENSION_EXACT` возвращает значение `TRUE` только для справочника `Города`, указанного в качестве аргумента функции, для справочника `Регионы` функция возвращает `FALSE`.  

При указании в качестве аргумента выборки `s. За границей `справочника `Города` результаты аналогичные. 

![Пример функций IN_DIMENSION и IN_DIMENSION_EXACT](f-in_dimension_exact-result-001.png)

При выборе аргументом измерения `Days` [IN_DIMENSION](in_dimension.md) возвращает значения `TRUE` для измерения `Days` и всех измерений выше по иерархии. Функция `IN_DIMENSION_EXACT` возвращает `TRUE` только для измерения `Days`.
