# IS_DESCENDANT
Возвращает `TRUE`, если элемент измерения является потомком хотя бы для одного из элементов, указанных в [] скобках.  

Функция является обратной функцией для [IS_ANCESTOR](is_ancestor.md). 

## Синтаксис

IS_DESCENDANT (X, [Y1, Y2, …]) 

## Аргументы 

- X: элемент измерения или выражение, возвращающее элемент измерения
- [Y1, Y2, ...]: множество элементов измерений или выражений, возвращающих элементы измерений. Функция возвращает `TRUE`, если `X` является потомком для хотя бы одного элемента этого множества. 

## Возвращаемое значение 

логический формат / Boolean 

## Эквивалент в Excel

нет 

### Примеры 

Рассмотрим мультикуб в строках которого справочник `Материки и города`, а в колонках кубы. Чтобы выделить дочерние элементы измерения для элемента `Африка`, используем формулу:  

```
IS_DESCENDANT(ITEM('Материки и города'), ['Материки и города'.'Африка']) 
```

Используем мультикуб `Селектор` с кубом `Материк` для демонстрации работы функции. 

Тогда дочерние элементы измерения для указанного значения материка в дополнительном кубе `Материк` определим по формуле: 

```
IS_DESCENDANT(ITEM('Материки и города'), ['Селектор'.'Материк'])
```
