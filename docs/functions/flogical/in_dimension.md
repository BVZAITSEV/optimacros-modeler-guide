# IN_DIMENSION
Проверяет, входит ли элемент `Y` в состав измерения `Х`.  

## Синтаксис

IN_DIMENSION(X)  

IN_DIMENSION(Х, Y) 

## Аргументы 

- X: измерение (или выборка) Справочника, Версий, Периода времени; 

- Y: выражение, возвращающее элемент измерения совместимого с X. Если не указано, то используется выражение ITEM(X). 

`Y` должно быть выражением, возвращающим элемент измерения, совместимого с `X`. Если это не так, то формула считается невалидной, и при попытке ее ввода генерируется ошибка.

## Возвращаемое значение 

логический формат / Boolean 

Возвращает `TRUE` если результат вычисления `Y` содержится в `X`. Иначе возвращает `FALSE`. 

## Эквивалент в Excel
