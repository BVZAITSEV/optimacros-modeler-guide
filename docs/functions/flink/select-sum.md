## SELECT и SUM или SUMIF

Применяются для передачи числовых данных из одного куба в другой с промежуточным суммированием. Часто используемый случай SELECT, когда в качестве аргумента X используется выражение с формулой [SUM](sum.md).

Суммируются элементы куба `X`, и возвращаются только суммы, удовлетворяющие критериям `y1, …, yk`. В некоторых случаях позволяет избежать построения промежуточного куба с функцией [SUM](sum.md).  

Обеспечивает высокую скорость расчетов и гарантирует согласованность данных за счет работы только по листовым элементам. 

## Синтаксис SELECT(SUM())

```
SELECT(SUM(X), Y1:y1, …, Yk: yk)
```

```
SELECT(SUM(X, Z1, ..., Zm), Y1:y1, …, Yk: yk) 
```

```
SELECT(SUM(X, [D1, …, Dn]), Y1:y1, …, Yk: yk)
``` 

```
SELECT(SUM(X, Z1, ..., Zm, [D1, …, Dn]), Y1:y1, …, Yk: yk)
``` 
- X — куб с числовыми значениями, участвующими в расчетах
- Y1 - измерение мультикуба-источника, по которому нужно отфильтровать значения, y1 — его элемент
- Z1 — куб в формате измерения, на котором будет построен виртуальный мультикуб
- D1 — cовпадающее измерение мультикуба-источника и приемника, по которому данные не суммируются


Суммирование выполняется по всем измерениям куба  `X`, кроме `Y1, …, Yk, Z1, …, Zm, D1, …, Dn`. Таким образом, Y:y1 — фильтр получаемых данных по измерению мультикуба-источника. Также zy может быть кубом в формате измерения Y1 при условии, что он построен на тех же измерениях, что и куб-приемник данных.

В отличие от обычного [SUM](sum.md) и [SUMIF](sumif.md), `X` не может быть выборкой куба. Кроме того, нельзя использовать синтаксис `SUM(…,AS(…))` и `SUMIF(…,AS(…))`. 


## Синтаксис SELECT(SUMIF())

Синтаксис **SELECT(SUMIF())** аналогичен **SELECT(SUM())**, с той лишь разницей, что появляется куб-условие. В данном случае измерения `[D1, …, Dn]`, исключаемые из общего суммирования, при их наличии, явно указываются перед кубом условием: 

```
SELECT(SUMIF(X, B), Y1:y1, …, Yk: yk)
```

```
SELECT(SUMIF(X, [D1, …, Dn], B), Y1:y1, …, Yk: yk)
```

```
SELECT(SUMIF(X, Z1, ..., Zm, B), Y1:y1, …, Yk: yk)
```  

```
SELECT(SUMIF(X, Z1, ..., Zm, [D1, …, Dn], B), Y1:y1, …, Yk: yk)
```

где `B` – куб в логическом формате. 

## Аргументы

- X: куб в числовом формате (Число/Number)
- Y1, …, Yk: измерения присутствующие в кубе X
- y1, …, yk: выражения возвращающее элемент соответствующего измерения
- Z1, …, Zm: кубы формата Справочник, Период времени, Версии, Выборка Кубов
- D1, …, Dn: опционально – измерения, по которым суммирование не будет производиться

## Возвращаемое значение 

Числовой формат 


## Особенности совместного использования SELECT и SUM (SUMIF)

- Формула автоматически не учитывает совпадающие измерения мультикуба-источника и приемника.

- В функции SUM можно использовать дополнительные аргументы, которые указываются в квадратных скобках последними. Если совпадающие измерения двух мультикубов перечислены в квадратных скобках, то формула их учтет. Все измерения, по которым не производится суммирование, указываются в одних квадратных скобках. 

- Если внутри функции SUM используются аргументы-кубы (Z1), то измерения, выбранные в качестве форматов этих аргументов, будут использованы для построения виртуального мультикуба, который для функции SUM будет являться приемником, а для функции SELECT — источником.

    При попытке получить значения для куба `К1` с помощью выражения:

    
    SELECT(SUM('Продажи в разрезе компаний и продуктов'.'Выручка от продаж'), 'Продукты':'Продукты'.'Фрукты')

## Пример 2

Для куба `К2` выполнение формулы:

```
SELECT(SUM('Продажи в разрезе компаний и продуктов'.'Выручка от продаж'), 'Продукты':'Продукты'.'Яблоки')
```

суммирует все измерения куба `'Выручка от продаж'` кроме измерения `'Продукты'`, так как оно указано в SELECT-е. В результате все ячейки куба получают одно и то же значения суммы для яблок, так как в нем нет измерения `'Продукты'`.

Аналогичный результат можно получить при использовании промежуточного куба с одним измерением `'Продукты'` и установленной для него формулой:

```
SUM('Продажи в разрезе компаний и продуктов'.'Выручка от продаж') 
```


![Промежуточный куб с одним измерением `'Продукты'` и установленной для него формулой](f-select-sum-result-002.png)


## Пример 3

Куб `К4` рассчитывается по формуле:

```
SELECT(SUM('Продажи в разрезе компаний и продуктов'.'Выручка от продаж', ['Months', 'Versions']), 'Продукты':'Продукты'.'Яблоки')
```

В данном случае применено явное исключение из суммирования измерений, которые не должны в нем участвовать – `Версии` и `Время`.
