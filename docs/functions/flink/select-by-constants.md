# SELECT по константам
Возвращает в куб значения из куба X, отфильтрованные по элементу Y1 измерения Y. 

## Синтаксис

SELECT(X, Y: Y1) 

## Аргументы 

- X: куб в формате Number, Date, Time Period, Boolean, List, Text, Versions, Cube Subset
- Y: измерение, используемое в мультикубе (формат List, Time Period, Versions, Cube Subset и их выборки)
- Y1: элемент измерения 

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х.

## Эквивалент в Excel

ПРОСМОТР/LOOKUP

Для куба `Выручка от продаж_Фрукты` функция **SELECT** принимает из куба `Выручка от продаж` мультикуба `Продажи` сумму всех дочерних продуктов элемента `Фрукты` справочника `Продукты`: 

```
SELECT(Продажи.'Выручка от продаж', Продукты: Продукты.Фрукты)
```


Для куба `Выручка от продаж_Овощи` функция **SELECT** принимает из куба `Выручка от продаж` мультикуба `Продажи` сумму всех дочерних продуктов элемента `Овощи` справочника `Продукты`: 

```
SELECT(Продажи.'Выручка от продаж', Продукты: Продукты.Овощи)
```

### Примеры синтаксиса 

### Использование полных измерений в SELECT с аргументом-константой (элемент измерения)

- `'Мультикуб1'.'Куб1'` содержит измерение `Справочник1`:
    ```
    SELECT(‘Мультикуб1’.’Куб1’, ‘Справочник1’ : ‘Справочник1’.’Элемент1’)
    ``` 
- `'Мультикуб1'.'Куб1'` содержит измерение `Versions`:
    ```
    SELECT('Мультикуб1'.'Куб1', Versions : Versions.Факт)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `Months`:
    ```
    SELECT('Мультикуб1'.'Куб1', Months : Months.’Jan 19’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерения `Справочник1`, `Versions` и `Months`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘Справочник1’ : ‘Справочник1’.’Элемент1’, Versions : Versions.Прогноз, Months: Months.’Feb 19’)
    ```
!!! warning inline end ""
    в разработке 
- `'Мультикуб1'.'Куб1'` содержит измерение `куб-сабсет cs.КубСабсет1`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘cs.КубСабсет1’ : ‘cs.КубСабсет1’.’Куб55’)
    ```
!!! warning inline end ""
    в разработке 
- `'Мультикуб2'.'Куб1'` содержит измерения `Справочник1`, `cs.КубСабсет1`, `Versions` и `Months`:
    ```
    SELECT('Мультикуб2'.'Куб1', ‘Справочник1’ : ‘Справочник1’.’Элемент1’, Versions : Versions.Прогноз, ‘cs.КубСабсет1’ : ‘cs.КубСабсет1’.’Куб55’, Months: Months.’Feb 19’)
    ``` 

### Использование выборок в **SELECT** с аргументом-константой (элемент выборки/измерения) 

- `'Мультикуб1'.'Куб1'` содержит измерение s.СабсетСправочника1 (выборка полного измерения `Справочник1`): 
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Справочник1’.’Элемент2’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетВерсий` (выборка полного измерения `Versions`): 
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетВерсий’ : Versions.Факт)
    ``` 
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетMonths` (выборка полного измерения `Months`): 
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетMonths’ : Months.’May 19’)
    ```
- `'Мультикуб1'.'Куб1' `содержит выборки измерений `s.СабсетСправочника1`, `s.СабсетВерсий` и `s.СабсетMonths`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Справочник1’.’Элемент3’, s.СабсетMonths : Months.’Sep 19’, ‘s.СабсетВерсий’: Versions.Прогноз)
    ```
!!! warning inline end ""
    в разработке 
- `'Мультикуб1'.'Куб1'` содержит измерение куб-сабсет `cs.КубСабсет2` 
    ```
    SELECT('Мультикуб1'.'Куб1', ‘cs.КубСабсет2’ : ‘cs.КубСабсет2’.’Куб55’)
    ```
!!! warning inline end ""
    в разработке   
- `'Мультикуб1'.'Куб1'` содержит измерения `s.СабсетСправочника1`, `s.СабсетВерсий`, выборка кубв `cs.КубСабсет2` и `s.СабсетMonths`: 
    ```
    SELECT('Мультикуб2'.'Куб1', ‘s.СабсетСправочника1’ : ‘Справочник1’.’Элемент3’, s.СабсетMonths : Months.’Sep 19’, ‘s.СабсетВерсий’: Versions.Прогноз, ‘cs.КубСабсет2’ : ‘cs.КубСабсет2’.’Куб55’)
    ```
