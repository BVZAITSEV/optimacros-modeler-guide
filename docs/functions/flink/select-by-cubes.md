# SELECT по кубам
Возвращает в куб значения из куба X, в соответствии со значениями куба Y в формате измерения Z. 

Используется в тех случаях, когда требуется присвоить значения каждой ячейке куба-приёмника таким образом, чтобы они соответствовали определённым элементам измерений мультикуба-источника. Эти элементы должны находиться на пересечении определённых элементов измерений мультикуба-приёмника.

## Синтаксис

SELECT(X, Z:Y, Z1:Y1, ...) 

## Аргументы 

- X: куб, из которого нужно получить значения. Допустимы форматы Number, Date, Time Period, Boolean, List, Text, Versions, Cube Subset.
- Y: куб в формате измерения Z, ячейки которого находятся на пересечении тех же измерений, что и ячейки куба-приемника данных. Допустимы форматы List, Time Period, Versions, Cube Subset (и их выборки).
- Z: измерения мультикуба-источника, по которым нужно отфильтровать получаемые значения. Допустимы форматы List, Time Period, Versions, Cube Subset (и их выборки).

Таким образом, Z:Y, Z1:Y1 - являются фильтрами получаемых данных по указанным измерениям в их формате

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х.

## Эквивалент в Excel

ПРОСМОТР/LOOKUP 


## Особенности функции SELECT по кубам

- Результат работы функции SELECT по кубам имеет такой же формат, как и куб, из которого берутся данные.
- Для фильтрации данных можно использовать только те измерения, которые присутствуют в исходном мультикубе.
- Для одного измерения можно использовать только один фильтр.
- Значения ячеек кубов в фильтрах могут быть как родительскими, так и дочерними элементами измерений. Также возможно использование пустых значений ячеек. В этом случае система не выдаст ошибку, а оставит соответствующую ячейку куба-приёмника незаполненной.
- Куб, используемый в качестве аргумента после двоеточия, должен соответствовать измерению, указанному до двоеточия. Куб должен находиться либо в исходном мультикубе, либо в мультикубе, построенном на тех же измерениях, что и исходный.
- В качестве аргумента после двоеточия можно указать формулу, результатом которой являются элементы измерения, указанного до двоеточия.
- Если не указывать фильтры по совпадающим измерениям исходного мультикуба и куба-приёмника, то автоматически будут получены значения, относящиеся к соответствующим элементам.
- Если измерение отсутствует в исходном мультикубе, но присутствует в кубе-приёмнике, то при отсутствии фильтра по этому измерению будут автоматически получены значения, соответствующие его верхнему уровню. Если верхнего уровня нет, система выдаст ошибку.


## Пример 1 

Предположим, что требуется найти зарплату для каждого сотрудника из таблицы выплат в зависимости от класса и региона. 

Исходный мультикуб содержит в качестве измерений справочники `Оценка` и `Регионы`. 

![Исходный мультикуб содержит в качестве измерений справочники `Оценка` и `Регионы`](f-select-by-cubes-source-one.png){data-gallery="001"}

Полученный мультикуб в строках содержит справочник сотрудников, в столбцах - кубы `Оценка` и `Регион` в формате соответствующих справочников. 

![Полученный мультикуб в строках содержит справочник сотрудников, в столбцах - кубы `Оценка` и `Регион` в формате соответствующих справочников](f-select-by-cubes-result-one.png){data-gallery="001"}

В кубе `Зарплата` определим зарплату сотрудникам, из данных исходного модуля, в соответствии с регионом и классом, с помощью формулы 

```
SELECT('Таблица выплат'.'Базовая выплата', Оценка: Оценка, Регионы: Регион) 

```

## Пример 2 

Исходный мультикуб `Трудозатраты` по проектам в качестве измерения времени содержит `Years`, полученный мультикуб `План по проектам` в качестве измерения времени содержит `Months`, остальные измерения одинаковые.  

 ![Исходный мультикуб `Трудозатраты` по проектам в качестве измерения времени содержит `Years`](f-select-by-cubes-source-two.png){data-gallery="002"}

С помощью функции **SELECT** определим значения для куба `Трудозатраты` результирующего мультикуба для каждого месяца соответствующего года: 

```
SELECT('Трудозатраты по проектам'.Трудозатраты, Years: PARENT(ITEM(Months))) * Длительность 
```

![Полученный мультикуб `План по проектам` в качестве измерения времени содержит `Months`](f-select-by-cubes-result-two.png){data-gallery="002"}
 

### Примеры синтаксиса 

### Использование полных измерений в SELECT с аргументом кубом 

- `'Мультикуб1'.'Куб1'` содержит измерение `Справочник1`, а куб `Мультикуб2.Куб2` в формате `Справочник1` или `s.СабсетСправочника1`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘Справочник1’ : ‘Мультикуб2’.’Куб2’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `Versions`, а куб `Мультикуб2.Куб3` в формате `Versions` или `s.СабсетВерсий`:
    ``` 
    SELECT('Мультикуб1'.'Куб1', Versions : ‘Мультикуб2’.’Куб3’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `Months` и `Мультикуб2.Куб4` в формате `Months` или `s.СабсетMonths`:
    ```
    SELECT('Мультикуб1'.'Куб1', Months : ‘Мультикуб2’.’Куб4’)
    ```
- `Мультикуб1'.'Куб1'` содержит измерение `cs.КубСабсет` и `Мультикуб2.Куб5` в формате `cs.КубСабсет`
    ```
    SELECT('Мультикуб1'.'Куб1', ‘cs.КубСабсет’ : ‘Мульиткуб2’.’Куб5’)
    ```
- `Мультикуб1'.'Куб1'` содержит измерения `cs.КубСабсет`, `Справочник1`, `Versions` и `Months`; и `Мультикуб2.Куб2` в формате `Справочник1`, `Мультикуб2.Куб3` в формате `Versions`, `Мультикуб2.Куб4` в формате `Months`, `Мультикуб2.Куб5` в формате `cs.КубСабсет`:
    ```
    SELECT('Мультикуб1'.'Куб1', Versions : ‘Мультикуб2’.’Куб3’, ‘Справочник1’ : ‘Мультикуб2’.’Куб2’, ‘cs.КубСабсет’ : ‘Мультикуб2’.’Куб5’, Months : ‘Мультикуб2’.’Куб4’)
    ```

### Использование выборок в SELECT с аргументом кубом 

- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетСправочника1` и `Мультикуб2.Куб6` в формате `s.СабсетСправочника1` или в формате полного измерения `Справочник1`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Мультикуб2’.’Куб6’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетВерсий` и `Мультикуб2.Куб7` в формате `s.СабсетВерсий` или в формате полного измерения `Versions`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетВерсий’ : ‘Мультикуб2’.’Куб7’)
    ``` 
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетМесяцев` и `Мультикуб2.Куб8` в формате `s.СабсетМесяцев` или в формате полного измерения `Months`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетМесяцев’ : ‘Мультикуб2’.’Куб8’)
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `cs.КубСабсет` и `Мультикуб2.Куб9` в формате `cs.КубСабсет`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘cs.КубСабсет’ : ‘Мультикуб2’.’Куб9’)
    ```
- `'Мультикуб1'.'Куб1'` содержит выборки измерений `s.СабсетСправочника1`, `s.СабсетВерсий`, `s.СабсетМесяцев`, `cs.КубСабсет`; и `Мультикуб2.Куб6` в формате `s.СабсетСправочника1`, `Мультикуб2.Куб7` в формате `s.СабсетВерсий`, `Мультикуб2.Куб8` в формате `s.СабсетМесяцев`, `Мультикуб2.Куб9` в формате `cs.КубСабсет`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Мультикуб2’.’Куб6’, ‘s.СабсетВерсий’ : ‘Мультикуб2’.’Куб7’, ‘s.СабсетМесяцев’ : ‘Мультикуб2’.’Куб8’, ‘cs.КубСабсет’ : ‘Мультикуб2’.’Куб9’)
    ```
 

!!! info "" 
    Аргументы-кубы в SELECT могут быть из разных мультикубов 

- `'Мультикуб1'.'Куб1'` содержит выборки измерений `s.СабсетСправочника1`, `s.СабсетМесяцев`, `cs.КубСабсет`; и `Мультикуб3.Куб2` в формате `s.СабсетСправочника1`, `Мультикуб2.Куб8` в формате `s.СабсетМесяцев`, `Мультикуб2.Куб9` в формате `cs.КубСабсет`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Мультикуб3’.’Куб2’, ‘s.СабсетМесяцев’ : ‘Мультикуб2’.’Куб8’, ‘cs.КубСабсет’ : ‘Мультикуб2’.’Куб9’)
    ```
 

### SELECT со смешанными аргументами 

Аргументы могут быть различными по типу измерений (полные измерения и выборки полных измерений) или по типу аргументов (константы-элементы измерений и кубы).

- `'Мультикуб1'.'Куб1'` содержит измерения `s.СабсетСправочника1`, `Versions`, `s.СабсетMonths`, `cs.КубСабсет1`; и `Мультикуб2.Куб2` в формате `s.СабсетСправочника1`, `Мультикуб2.Куб3` в формате `s.СабсетMonths`, `Мультикуб2.Куб4` в формате `cs.КубСабсет1`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : ‘Мультикуб2’.’Куб2’, Versions: Versions.’Прогноз 6’, ‘s.СабсетMonths’ : ‘Мультикуб2’.’Куб3’, ‘cs.КубСабсет1’ : ‘Мультикуб2’.’Куб4’)
    ```  
- `'Мультикуб1'.'Куб1'` содержит измерения `Справочник1`, `s.СабсетВерсий`, `Months`, `cs.КубСабсет3`; и `Мультикуб2.Куб3` в формате `Months` или `s.СабсетMonths`, `Мультикуб2.Куб1` в формате `cs.КубСабсет3`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘Справочник1’ : ‘Справочник1’.’Элемент1’, ‘s.СабсетВерсий’ : Versions.’Прогноз’, Months : ‘Мультикуб2’.’Куб3’, ‘cs.КубСабсет3’ : ‘Мультикуб2’.’Куб1’)
    ``` 

!!! info ""
    Форматы аргументов-кубов в SELECT могут быть из полных измерений или из любых выборок полных измерений 

- `'Мультикуб1'.'Куб1'` содержит измерения `s.СабсетСправочника1`, `Versions`, `s.СабсетMonths`, `cs.КубСабсет`; и `Мультикуб2.Куб9` в формате `Справочник1`, `Мультикуб2.Куб10 `в формате `Months`, `Мультикуб2.Куб8` в формате `cs.КубСабсет`:
    ```
    SELECT('Мультикуб1'.'Куб1', 's.СабсетСправочника1': ‘Мультикуб2’.'Куб9', Versions: Versions.'Прогноз 6', 's.СабсетMonths': ‘Мультикуб2’.'Куб10', 'cs.КубСабсет': ‘Мультикуб2’.'Куб8')
    ```
- `'Мультикуб1'.'Куб1'` содержит измерения `s.СабсетСправочника1`, `Versions`, `s.СабсетMonths`, `cs.КубСабсет`; и `Мультикуб2.Куб6` в формате `s.ЕщёСабсетСправочника1`, `Мультикуб2.Куб7` в формате `s.ЕщёСабсетMonths`; `Мультикуб2.Куб8` в формате `cs.КубСабсет`
    ```
    SELECT('Мультикуб1'.'Куб1', 's.СабсетСправочника1': ‘Мультикуб2’.'Куб6', Versions: Versions.'Прогноз 6', 's.СабсетMonths': ‘Мультикуб2’.'Куб7', 'cs.КубСабсет': ‘Мультикуб2’.'Куб8')
    ```
- `'Мультикуб1'.'Куб1'` содержит измерения `Справочник1`, `Справочник2`, `s.СабсетВерсий, Months`, `cs.КубСабсет3`; и `Мультикуб2.Куб3` в формате `Months`, `s.СабсетMonths` или `s.ЕщёСабсетMonths` , `Мультикуб2.Куб4` в формате `cs.КубСабсет1`, `Мультикуб2.Куб5` в формате `Справочник2`, `s.СабсетСправочника2` или `s.ЕщёСабсетСправочника2`:
```
SELECT('Мультикуб1'.'Куб1', 'Справочник1': 'Справочник1'.'Элемент1', 's.СабсетВерсий': Versions.Прогноз, Months: ‘Мультикуб2’.'Куб3', 'cs.КубСабсет3': ‘Мультикуб2’.'Куб4', 'Справочник2': ‘Мультикуб2’.'Куб5')
```
