# PROPERTY
Возвращает свойство элемента справочника X. 

## Синтаксис

PROPERTY(Х.'Property', X) 

## Аргументы
- X: формат Справочника, который может быть рассчитан как `X= ITEM(X) `

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х 

## Эквивалент в Excel

Нет 

## Пример

Данный пример включает простой двумерный мультикуб, кубы которого представлены в столбцах, и справочник `Продукты` в строках. Куб `Регион` использует функцию [ITEM](item.md) для возврата элемента справочника `Продукты` для строки, после чего функция `PROPERTY` возвращает свойство элемента этого справочника. 

```
PROPERTY(Продукты.'св-во.Регион', ITEM(Продукты))
```

!!! tip "Подсказка"
    Можно возвращать свойства родительского элемента, дополнительно используя функцию PARENT: 
    ```
    PROPERTY(Х.'Property', PARENT(X)) 
    ```
