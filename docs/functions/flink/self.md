# SELF 
Возвращает содержимое ячейки куба с координатой по измерению X, соответствующей значению выражения Y или смещенной на значение Y, если Y - целое число. 

В отличие от функций **SELECT**, получает значения из того же куба, в котором функция применяется.

## Синтаксис

SELF(X1: Y1,…, Xn: Yn) 

## Аргументы 

- X1…Xn: измерения мультикуба, в котором используется **SELF**. По ним отфильтрованы получаемые значения

- Y1…Yn: Элементы измерений X1…Xn, откуда берутся значения. Или кубы в формате измерений, имеющие одинаковый набор измерений с кубом-приемником данных. Или целые числа, не равные 0, означающие смещение относительно текущей ячейки по измерениям X1…Xn.

Таким образом, X1: Y1, Xn: Yn - это фильтры получаемых данных по разным измерениям (Х1 и Xn) и их элементам,
либо кубам в их формате, либо смещением относительно текущей ячейки (Y1, Yn).

!!! note "Важно"
    - Смещение может быть указано любым целым числом (как положительным, так и отрицательным), кроме 0.
    - Чтобы применить константу или куб после двоеточия, хотя бы один из фильтров должен быть смещением.
    - Если в формуле используется SELF со смещением по нескольким измерениям, то время выполнения операции значительно увеличивается.
    - Не следует использовать функцию SELF в виртуальных кубах с большим числом элементов в измерении. У всех текстовых кубов виртуализация включена по умолчанию.
    - Выражения в аргументах SELF не должны возвращать родительский элемент, чтобы избежать рекурсии.


## Возвращаемое значение 

Соответствует формату данных исходного куба. 

## Эквивалент в Excel

СМЕЩ/OFFSET
