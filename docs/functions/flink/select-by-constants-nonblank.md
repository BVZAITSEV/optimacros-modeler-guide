# SELECT по константам с параметрами FIRSTNONBLANK и LASTNONBLANK

Возвращает в куб первое непустое (FIRSTNONBLANK) или последнее непустое (LASTNONBLANK) значение из куба X по измерению Y, отфильтрованное по элементу Z1 измерения Z. 

## Синтаксис

SELECT(X, Y: FIRSTNONBLANK(), Z: Z1) 

SELECT(X, Y: LASTNONBLANK (), Z: Z1) 

## Аргументы 

- X: куб в формате Number, Date, Time Period, Boolean, List, Text, Versions, Cube Subset
- Y: измерение, используемое в мультикубе (формат List, Time Period, Versions, Cube Subset и их выборки
- Z: измерение, используемое в мультикубе (формат List, Time Period, Versions, Cube Subset и их выборки)
- Z1: элемент измерения 

## Возвращаемое значение 

Соответствует формату данных, используемых аргументом Х 

## Ограничения

Использование более одного параметра **FIRSTNONBLANK** и **LASTNONBLANK** на данный момент не поддерживается.

### Примеры синтаксиса

Мультикуб, в строках которого находятся кубы и нумерованное измерение `Нум 10`, измерение времени `Months` - в колонках. 

### Синтаксис для FIRSTNONBLANK

```
SELECT('Value', 'Нум 10':FIRSTNONBLANK(), 'Months':'Months'.'Jan 18')
```

В результате применения формулы получаем значение 390 - первое непустое значение куба `Value` по измерению `Нум 10`, отфильтрованное по элементу `Jan 18` измерения `Months`, для всех элементов измерения `Months`. 

### Синтаксис для LASTNONBLANK

```
SELECT('Value', 'Нум 10':LASTNONBLANK(), 'Months':'Months'.'Jan 18')
``` 

В результате применения формулы получаем значение 19 - последнее непустое значение куба `Value` по измерению `Нум 10`, отфильтрованное по элементу `Jan 18` измерения Mon`ths, для всех элементов измерения `Months`. 

### Синтаксис при использовании выборок

- `Мультикуб1'.'Куб1'` содержит измерение `s.СабсетСправочника1` (выборка полного измерения `Справочник1`):
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетСправочника1’ : FIRSTNONBLANK())
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетВерсий` (выборка полного измерения `Versions`):
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетВерсий’ : FIRSTNONBLANK())
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение `s.СабсетMonths` (выборка полного измерения `Months`):
    ```
    SELECT('Мультикуб1'.'Куб1', ‘s.СабсетMonths’ : FIRSTNONBLANK())
    ```
- `'Мультикуб1'.'Куб1'` содержит измерение выборка куба `cs.КубСабсет2`:
    ```
    SELECT('Мультикуб1'.'Куб1', ‘cs.КубСабсет2’ : FIRSTNONBLANK())
    ```
