# Время

Измерение Время является неотъемлемой частью системы и всегда участвует в создании реальных моделей. Большинство моделей требуют использования временных параметров в своих мультикубах. Без учёта временных рамок невозможно определить сроки планирования. Необходимо учитывать расходы и доходы по дням, неделям, месяцам, кварталам, полугодиям и годам.

Параметры времени должны быть определены на начальном этапе создания модели, как описано в разделе [Настройки календаря](time-calendar-settings.md). Изменение временных параметров после создания основных справочников и мультикубов может привести к потере данных и дополнительным затратам времени на корректировку модели.


## Справочники времени

Для работы с типами измерения **Время** используется тот же подход, что и при работе с справочниками. Чтобы открыть тип измерения **Время**, нужно перейти в меню **Измерения** и выбрать **Время**:

![меню Измерения Время](model-control-dictionaries-time-menu.png)

В справочнике времени представлены элементы, используемые в модели, такие как годы, месяцы, дни и кварталы. Каждому элементу справочника времени может быть присвоен уникальный идентификатор, который используется для синхронизации и интеграции между моделями.

![Справочники времени](model-control-dictionaries-time.png)

!!! tip "Важно"
    Часть измерений времени в меню неактивна по умолчанию, так как в настройках календаря выключены установки  **Отображать итоги кварталов** и **Отображать итоги полугодий**.

В системе временные интервалы связаны между собой иерархически, где один тип выступает в роли "родителя" по отношению к другому:

| Интервал | Имя системного справочника <br/> (используется в формулах) | Родительский справочник <br/> (PARENT) |
| --- | --- | --- |
| Год | Years | - |
| Полугодие | Half Years | Год |
| Квартал | Quarters | Полугодие |
| Периоды | Periods | Квартал |
| Месяц | Months | Квартал |
| Неделя | Weeks | Месяц |
| День | Days | Неделя |

## Свойства времени

Свойства измерения **Время** позволяют добавить дополнительную информацию элементам измерения, например, указать количество дней в месяце. Чтобы создать новое свойство, необходимо открыть соответствующий временному интервалу справочник в режиме редактирования и воспользоваться стандартными способами добавления элементов, или воспользоваться основным меню:

![Время - Добавить Свойство](model-control-dictionaries-time-add-property.png)
