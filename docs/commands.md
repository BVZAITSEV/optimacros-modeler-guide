# Команды


## Представление - Открыть { #cmd-view-open }

![](cmd-open-multicube-view.png){ .off-glb }
Выбрать и открыть представление мультикуба. Возможен поиск по имени представления.


## Представление - Сохранить { #cmd-view-save }

Сохранить изменения в текущем представлении.

Перед выполнением операции появляется предупреждающий диалог:

![](cmd-save-multicube-view-warning-dialog.png){ .off-glb }


## Представление - Сохранить как { #cmd-view-save-as }

Появляется диалог **Сохранить как:** со следующими переключателями:

### Сохранить как: Новое
Сохранить представление, указав ему новое имя:

![](cmd-save-as-new-multicube-view.png){ .off-glb }

### Сохранить как: Существующее
Перезаписать существующее представление. Необходимо выбрать представление из выпадающего списка:

![](cmd-save-as-exisitng-multicube-view.png){ .off-glb }

Отключите опцию **Использовать текущие фильтры** чтобы сбросить в сохраненном представлении выбранные значения фильтров над таблицей мультикуба.

Отключите настройку **Глобальное представление** чтобы создать персональное представление, то есть представление, которое видит только пользователь, создавший его.

## Менеджер представлений { #cmd-view-manager }

Менеджер представлений позволяет упорядочить список представлений, переименовать и удалить представления. 

![](cmd-view-manager-multicube-view.png){ .off-glb }

Представления распределены по двум вкладкам - **Глобальные** представления, то есть видимые всем, и **Персональные**, то есть представления, которые видит только пользователь, создавший их.

Чтобы переместить представление в списке, нажмите левой кнопкой мыши на многоточие рядом с названием нужного представления и, не отпуская ее, перетащите в нужное место в списке. Также можно отметить галочкой нужные представления и нажать на кнопку выбранного действия на боковой панели менеджера представлений.

## Печать { #cmd-view-print }

В этом окне вы можете отправить на печать страницу или таблицу, переключившись на нужную вкладку.

![](cmd-view-print-multicube-view.png){ .off-glb }

Способ печати **Печатать таблицу** рекомендуется для печати больших таблиц, выходящих за пределы одного экрана по высоте.

## Опубликовать на Контекстную таблицу  { #cmd-view-publish-to-context-table }

Копирует представление на [контекстную таблицу](visualization-context-tables.md), выбираемую из списка контекстных таблиц модели.

Уведомления о копировании не появляется, контекстная таблица - приемник автоматически не открывается.

## Опубликовать на Дашборд  { #cmd-view-publish-to-dashboard }

Копирует представление на [дашборд](visualization-dashboards.md), выбираемый из списка дашбордов модели.

Уведомления о копировании не появляется, дашборд - приемник автоматически не открывается.
