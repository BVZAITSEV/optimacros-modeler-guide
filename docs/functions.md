# Формулы и функции

**Формулы** — это выражения, с помощью которых выполняются вычисления в модели. Формулы могут включать в себя [функции](function-table.md). Простую формулу можно создать с помощью констант и простых арифметических операций. 

Особый вид формул - [формулы-ссылки](formula-reference.md). Формулой-ссылкой является выражение следующего формата: ```Объект.Элемент объекта```. В качестве объекта может выступать справочник или мультикуб. В качестве элемента объекта выступают элементы справочника или кубы соответственно. Формулы-ссылки возвращают значения объекта, на который они ссылаются. Формулы-ссылка на куб возвращает данные ячеек в разрезе измерений, которые включены в сводную таблицу мультикуба.

**Функции** — это заранее определенные формулы, которые выполняют вычисления по заданным величинам, называемым аргументами, и в указанном порядке.

Основным инструментом настройки объектов платформы Оптимакрос для моделера являются функции.

## Синтаксис функций
Формат синтаксиса функций Оптимакрос схож с математическими функциями или методами/функциями, которые используются в программировании:

**НАИМЕНОВАНИЕ ФОРМУЛЫ(Аргумент 1, …, Аргумент N)**

Функция может возвращать следующие типы данных:

- Число
- Текст
- Элемент измерения
- Дата
- Булево (логическое) значение
- Пустое значение, 0 или NaN


Моделер использует функции в реализации моделей, для настройки автоматического определения значения в ячейках свойств справочников и кубов Мультикубов. 

## Вложенные функции

Некоторые функции могут быть вложены друг в друга. Функция, которая применяется в качестве аргумента, должна выдавать данные того же типа. В качестве аргумента формулы можно использовать другую формулу.

Тем не менее, не рекомендуется использовать комбинацию функций **SELECT** и [SUM](sum.md) вида `SELECT(SUM(Аргумент), Аргумент)` в проектах, так как это может негативно сказаться на производительности из-за увеличения количества итераций расчёта.


Следующие функции не поддерживают вложенность:

- [MIN](min.md), [MAX](max.md)... – <term:Агрегатные функции|агрегатные функции>
- LASTNONBLANK, default_value ...- функции без аргументов
- [GAUSS](gauss.md) и другие функции, которые используют числовые константы в качестве аргументов.

## Свичовер (Switchover)

В системе предусмотрен механизм переключения (switchover) между различными режимами отображения данных, который позволяет настроить отображение данных в зависимости от выбранной версии.

Для настройки переключения между версиями необходимо перейти в раздел **Версии** и выбрать версию, которая будет использоваться для отображения данных. Затем нужно установить версию, с которой будут браться данные, и период, с которого будет производиться подстановка данных.

Если переключатель используется на кубах, доступных для ввода, то периоды до установленного значения в поле `Дата начала прогнозного периода` будут недоступны для изменения и будут отражать данные с версии, установленной в поле `Переключатель Факт-Прогноз`.

Если на версии используется переключатель и изменяется период на следующий день, месяц или год, данные, которые были в ячейках до установленного периода, заменяются на данные версии, установленной в поле `Переключатель Факт-Прогноз`.

Чтобы включить переключатель в разных мультикубах, необходимо установить свойство `Включить Факт-Прогноз` на кубах внутри мультикуба. Если это свойство не установлено, данные из версии `факт` не будут заменять данные из версии `план`.
