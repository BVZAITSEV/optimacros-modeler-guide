# Мультикуб - табличное представление


## Общие сведения

После открытия мультикуба перед вами появится таблица, состоящая из ячеек, содержащих данные. Расположение значений в строках и столбцах определяется настройками, заданными при создании данного мультикуба. Чтобы их изменить, воспользуйтесь инструкцией, описанной в статье [Сводная таблица](pivot-table.md).

По умолчанию ячейки с голубым шрифтом предназначены для ввода данных, а ячейки с чёрным шрифтом показывают результат консолидации или вычислений.

![Мультикуб - табличное представление](multicubes-table-view.png)

!!! tip ""
    Данные можно копировать из других таблиц (например, листов Microsoft Excel) и вставлять при помощи комбинации клавиш ++ctrl+c++ и ++ctrl+v++.

## Режим редактирования

Кнопка ![](icon-gridviewpanel-togglemode.png){ .off-glb } в левом верхнем углу включает [режим редактирования](multicubes-edit-mode-view.md) мультикуба. Для переключения можно использовать комбинацию клавиш ++alt+1++ (сочетания клавиш описаны в разделе [Горячие клавиши](hotkeys.md)).

## Вкладки представлений

![Вкладки представлений](multicube-table-view-view-tabs.png)

На вкладках открыты все представления данного мультикуба. Представления также показаны на боковой панели Содержимое, перейти к представлению можно щелчком на его названии.

## Заголовок с названием мультикуба

Чтобы скопировать/изменить название мультикуба, нужно навести курсор на его название и выбрать соответствующую опцию во всплывающем меню.

Для переименования мультикуба в открывшемся окне редактирования нужно изменить название, подтвердить клавишей «Enter». Для выхода из окна редактирования без принятия изменений нажать клавишу «Esc».
Скопировать название мультикуба в буфер обмена также можно двойным кликом мыши по соответствующему названию.
