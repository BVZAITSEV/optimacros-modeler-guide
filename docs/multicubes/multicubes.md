# Мультикубы

**Мультикуб** представляет собой аналог сводной таблицы Excel, в котором строками, столбцами и фильтрами могут выступать справочники из раздела. Мультикубы состоят из набора кубов.

**Куб** (**Мера** в понятиях OLAP кубов, **Значение** в понятиях Сводных таблиц) – это многомерная конструкция, особенностью которой является единый формат данных.


## Новый мультикуб

Для создания мультикуба выберите пункт главного меню **Данные > Мультикубы > Добавить Мультикуб**. Откроется диалог **Новый Мультикуб**:


![Диалоговое окно Новый Мультикуб](multicubes-new-multicube.png)

### Добавление измерений

В диалоговом окне **Новый Мультикуб**, на вкладке **Основные** в столбце **Измерения и Выборки** представлены все справочники модели, которые могут быть использованы в качестве измерений мультикуба. Это могут быть измерения времени, версий, пользовательские справочники, а также выборки. 


При создании нового мультикуба основное измерение времени (в данном случае `Months`) добавляется автоматически, его можно убрать при необходимости. Какое именно измерение будет добавлено, зависит от настроек модели, описанных в статье [Настройки календаря](time-calendar-settings.md).

Для добавления новых измерений необходимо перетащить их из левой колонки в область **Новый Мультикуб**. При необходимости их можно вернуть обратно.

![Для добавления новых измерений необходимо перетащить их из левой колонки](multicubes-drag-dimension.png)


Переместите нужные измерения в поле **Новый Мультикуб**. Фильтр **Все типы измерений** позволяет выбрать нужный тип измерений. Для быстрого поиска по названию начните вводить название измерения или его часть в поисковой строке **Измерения и Выборки**. 

Кнопка **Удалить всё** убирает все добавленные измерения.

Кнопка **По умолчанию** возвращает исходные настройки, так что остается только основное измерение времени.

Кнопка **Разместить** автоматически распределяет добавленные измерения и справочники по строкам, колонкам и фильтрам:


![Кнопка РАЗМЕСТИТЬ автоматически распределяет добавленные измерения и справочники по строкам, колонкам и фильтрам](multicubes-razmestit.png)

### Добавление кубов

В поле **Кубы** вводятся наименования кубов с имеющимися данными для дальнейшего расчета (каждое наименование с новой строки).

![Добавление списка кубов](multicubes-add-list-of-cubes.png)

Ввод большого числа имен кубов удобен через диалоговое окно, для вызова которого необходимо нажать на значок ![](multicubes-edit-dialog-icon.png){ .off-glb } в поле **Кубы**:

![Окно для ввода списка кубов](multicubes-add-list-of-cubes-via-dialog.png)

После нажатия ++enter++ в виджете со списком кубов появляется возможность их индивидуальной настройки или удаления:

![Индивидуальная настройка или удаление кубов](multicubes-add-list-of-cubes-configuration.png)

### Задание имени и положения в списке

На вкладке **Расширенные** можно изменить название мультикуба. По умолчанию оно является комбинацией строки **New Multicube #** и целого числа. Название мультикуба в модели должно быть уникальным. 

На этой же вкладке можно разместить мультикуб в нужную папку и задать расположение мультикуба в выбранной папке или в общем списке мультикубов, если папка не выбрана.

Кнопка **По умолчанию** сбрасывает значения полей на вкладке.

![Вкладка Расширенные](multicubes-extended-tab.png)


### Создание мультикуба

При нажатии на кнопку **Создать** окно **Новый Мультикуб** закрывается и создается мультикуб с заданным именем и расположением, с выбранными справочниками и созданными кубами.

## Открытие мультикуба

Чтобы открыть мультикуб, воспользуйтесь одним из следующих способов:

- В главном меню выберите нужный мультикуб (**Данные > Мультикубы**)
- В раскрывающемся списке на боковой панели **Содержимое** найдите название мультикуба и щелкните по нему
- В таблице мультикубов модели выберите  нужный мультикуб и воспользуйтесь кнопкой ![](icon-toolbar-open.png){ .off-glb } (**Открыть**)  на панели инструментов

![Способы открытия мультикуба](multicubes-open-multicube.png)
